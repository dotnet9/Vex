# Vex 原型与实现核对（2026-10-08）

对照 Vex 自己的 `design/index.html`、`design/assets/theme.css` 和用户提供的标题栏局部图片，不套用 Demo 的尺寸和排版。依赖联调版本为 `14.0.1-dev.20261008.9`。

## 细节清单

| 位置 | Vex 原型 | 原实现差异 | 本轮结果/证据 |
| --- | --- | --- | --- |
| 标题底线 | 40px 标题栏、1px 普通 border | 完全缺少底线 | y=39 绘制 1px，内容起点仍 y=40；六主题验证 PNG 像素 |
| 品牌 | 左 12px、gap 8px、20px logo | 左 8px、gap 5px | 修正间距，标题内容显式占 40px |
| 菜单 | 12.5px、padding 3px 9px、gap 2px | 12px、通用菜单大内边距 | 仅标题菜单按原型调整 |

| 页签 | 顶留白 8px/10px、内容宽度、图标+文字+2px 下线 | 48px、等宽、无图标 | 独立紧凑模板，文件/大纲图标及文字随主题着色 |

| 源码 | 12.5px、语义高亮、深色底 | 深色仍浅底、URL 纯蓝 | 传全套 Vex 令牌；URL 跟随 LinkKey |

目录缩进、过滤框、动态文件名/时间戳保留真实功能。原型仅同步计划明确要求的「侧边栏」名称与勾选，其他内容作为参照。

## 验证

加载原有 Prism Shell/XAML，用 Avalonia.Headless + Skia 后台绘制。设置、草稿、最近记录换为内存服务，MCP 关闭；不删除草稿、不修改真实配置、不占用键鼠。

- 连续打开五份真实样例文件，未输入时均未修改；编辑后切换出现实际未保存浮层，取消保留修改。
- 恢复草稿与磁盘不同仍标为未保存；磁盘才是保存基线。
- 菜单勾选、侧栏宽度和内存持久化字段同步，四语言文案已调整。
- Light/Dark/Aquatic/Desert/Dusk/NightSky 生成首屏和正文中部图；普通标题对比度至少 4.5:1，选中色按原型 accent/accent-soft，不宣称选中色均达到 4.5:1。
- 六主题检查标题线实际像素、页签图标/紧凑尺寸、H1 普通边框和引用 3px 左线。
- Release 构建通过；依赖库 182 项 Release 测试通过；两个仓库 diff 空白检查通过。

截图/日志在 `artifacts/ui-verification/`，不纳入 Git：`vex-Light-header.png`、`vex-Dark-header.png`（标题局部）；六主题首屏和 `*-middle.png`；`vex-980.png`；`vex-unsaved-confirmation.png`；`verification.log`。复现见 `scripts/ui-verification/README.md`。

## 边界与后续

1. 原型浏览器访问被环境拒绝，使用源码、用户图片与实现截图核对；没有全页逐像素对比结论。
2. 离屏不模拟 Windows 非客户区，不能用这里的系统窗控截图评价真实窗控；拖动/最大化、DPI、中文 IME 尚需实机检查。
3. 原型源码行高约 22px，原生编辑器更密；滚动条和字体度量尚未完全一致。
4. 修改列表/引用成员会规范化该组；复杂嵌套续行未穷尽，Demo 报告另列实时模式边界。
5. 四包开发版只在本地 nuget-local，未发布 NuGet/标签/安装包；运行窗口仍是旧代码，后台联调和 Release 构建采用隔离输出。下一轮先核对原生窗口/DPI与行距，再安排正式包联调。
