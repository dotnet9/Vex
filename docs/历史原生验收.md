# 原型与实现对照验收

2026-10-17：以当时仓库内的 HTML 原型为验收基准（与当前原型分别评审）。原生应用已接入单文档多视图、章节编排、独立窗口、六步引导及精简后的关于 / 鸣谢。本轮目标按用户最终更正为至少 98% 还原原型；除核心布局、操作和各视图同步，还逐项对照正文排版、侧栏行距、图标、分栏标题和弹窗。测试通过数量不能直接换算视觉还原率，最终仍需用户对照实际窗口确认。

## 当前对照范围

| 区域 | 已实现和检查的行为 |
| --- | --- |
| 文档 | 一个进程只有一份当前文档，文件导航切换时替换全部视图与副窗口，未保存时先确认 |
| 布局 | 八种固定布局；三块布局上方源码 / 渲染、下方导图；无 Dock 和多文档标签 |
| 独立窗口 | 移出和移回真实原生窗口；所有窗口共享文件、内容和撤销；源码与即时编辑互斥 |
| 即时编辑 | 点击保留文字起点与行高，保留行内格式、光标和选区；支持跨块导航、边界合并和撤销 |
| 代码块 | 静态无语言顶栏、无复制按钮；编辑时在下方显示代码类型，可修改、回到正文或 Esc 恢复；无额外空行、类型框完整可点击 |
| 插入与字体 | 行内代码和代码块采用不同图标；表格弹窗设置行列，取消保留选区、插入一次撤销；界面与代码调用系统已有字体，不随包分发字体 |
| 章节编排 | 标题 / 正文修改，同级 / 子级添加，升降级、上下移动、整章拖动、删除确认与保留正文、撤销 / 重做 |
| 导图 | 节点宽度、字体、分支间距、缩放与原型对照；保留摘要、仅标题、折叠、平移和源码定位 |
| 演示 | 正文按实际 Markdown 标题分页，文档大纲点击跳正文；导图只读平移、缩放、收折，双击 / Enter 跳正文；退出恢复编辑状态、阅读位置、布局及原独立窗口 |
| 选择面板 | 布局和排版立即预览并保持展开，支持连续比较；外部点击与 Esc 关闭 |
| 引导 | 六步覆盖写作、文件大纲、章节、布局、排版、保存分享；完成和跳过恢复原文、历史、偏好、视口与原副窗口实例 |
| 关于 / 鸣谢 | 品牌、Slogan、平台、版权及单一更新入口；鸣谢按实际直接依赖分组，一屏显示，Lite 不重复列出 |
| 主题和尺寸 | 八色浅深、四语；1280×820 和 980×640 的八布局截图对照 |

## 大文件与性能

已在 `D:\github\md\mds` 生成五份专用样本，包含 1.16 MB 混合技术文档、长代码、密集公式、数学符号、本地图像、Mermaid、脚注、宽表格和异常语法；同时只读使用用户提供的 RELAP 技术方案。

vex.19 性能采样完成六文档 × 八布局 × 明暗两轮，共 96 个组合、3,240 个滑块移动步骤。包含导图平移缩放、两轮三窗口换文档和十轮并发读取；全部原文件 SHA256 不变。vex.21 在横向滚动修正后再次完成全部压力组合，只作稳定性检查；最终 vex.22 另有多行段落软换行回归。

阅读改为按视口延迟建立实际内容；大导图按区域建立节点；长代码使用样式区间减少逻辑树开销。长代码阅读最慢拖动单步由约 2,480 ms 降至约 963 ms。复杂内容首次进入视口仍有数百毫秒停顿，不能称为性能已经完全达标。

详细样本、版本标记、计时环境与复现命令见 [性能与稳定性验证](../docs/性能与稳定性验证-20261017.md)。旧版冷进程性能记录不作为当前包的计时结果。

vex.24 进一步在最大化 1920×1280、Scaling 1 的离屏窗口完成 96 组合、3,240 个滑块步骤、12 次演示流程和原窗口恢复。短节切回长文档的全文物化回归已修复；大型混合文档退出演示时仅物化 15 / 3,524 块。最大化复杂内容首次布局仍有个别约 1.8 秒步骤，不能沿用较小窗口的最慢耗时作为本次结果。详见 `stress-maximized-vex24/stress.json`。

## 验收边界

- 98% 是视觉与体验对照目标，目前没有可证明达到该百分比的自动评分，功能断言通过数不等于视觉还原率。
- 两种尺寸的明暗截图已重新采集。原生字体栅格化、系统窗体装饰、部分图标和链接颜色仍与浏览器存在差异，不能仅凭主体布局相近就宣称目标完成。
- 文件树保留真实层级和排序；表格按内容分配列宽，原型固定样例顺序和列宽不作为伪造数据的理由。
- 实际多显示器、跨 DPI 与完整中文输入法组合仍需专项实测；同屏独立窗口和文字注入不能替代。
- 跨段选择已覆盖，跨表格字符选区与复杂结构的源码偏移仍需扩展场景；短时内存回落不能证明所有路径都没有泄漏。
- 依赖仍有裁剪和 NativeAOT 分析警告；正式包必须独立检查，托管回归不能代替。
