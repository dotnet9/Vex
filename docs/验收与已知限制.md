## 本轮原型验收重点

- 保留原有八种桌面布局、七组菜单、文件 / 大纲 / 导图、编辑与引导流程。
- 只保留 Windows、Linux、macOS 应用与安装入口；EXE、DEB、DMG 对应五 RID。
- 16 套配色和 27 套排版均可选择；重名风格有独立 Key，默认外观保持一致。
- 正文排版弹层同时呈现各套效果卡片，可竖向滚动；浏览不应用，点击或 Enter 应用，选择后保留比较位置。
- 同一语义资源 Key 驱动浅深色、标题、正文、代码、表格、弹窗和选择状态；切换风格不改原文及撤销历史。
- 表格按内容分列，短标签列不等分占宽；长中文、长链接、宽表格和多视图可读。
- 甘特图、C4 与 XY 图保留文字可读尺寸，宽图局部滚动；图表范围见 [Markdown 图表](Markdown图表.md)。
- 标题栏外观、语言与窗口按钮水平对齐；导图的文档 / 标题层级提示与标题同行，保持次要层级。
- 版本、帮助、鸣谢、项目链接、公式与字体资源均可从本仓库离线读取。

## 应用后续验收

原型合并资源尚未同步进入 Avalonia 应用。当前应用仍为八套配色、十八套正文排版；原型中的辅助面板、引导、更新入口或设置细节应逐项对照再实现。

Windows 的真实输入法、多 DPI、跨屏、文件锁、关联注册、安装 / 取消 / 卸载和迁移仍需对应场景。Linux、macOS 不能用 Windows 上的构建契约替代真实安装、桌面集成、权限、Finder 与 Gatekeeper 检查。

Markdown 引擎、浏览器原型和各导出格式对复杂 SVG、数学、化学、Mermaid、嵌套结构、字体和分页的支持不完全相同。验收应检查实际图形和导出文件，不能以非空字节或模板数量推导完整兼容性。

性能比较应固定机器、文档、构建方式与运行时，记录首次打开、首次阅读和后续切换；离屏编码耗时不能直接称为桌面冷启动。恢复、导出和 MCP 操作失败均须保留用户内容并给出可理解的状态。
