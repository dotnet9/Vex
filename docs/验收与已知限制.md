# 验收与已知限制

本文维护 **Vex 1.7.2** 的源码验证结果，以及 1.7.0 的历史正式交付证据、测量方法和已知边界，整理于 2026-10-21。应用、原型和安装包的既有结果来自相应验证记录，不表示文档整理时重新执行全部回归。逐版本中间记录已合并删除，历史过程可从 Git 追溯。

## 1. 当前交付结论

应用已接入 16 配色、27 正文排版、原型工作台、持久化导航、文件保护、辅助面板与动效。1.7.0 的五个正式安装包已发布，公开下载与 SHA256 核对通过；不能据此推断后续版本已完成发布。视觉 ≥98% 的量化证据仅覆盖 Windows 安装器中文五状态 × 明暗十张图，不能延伸为全应用或所有平台的已验证结论。

| 验证层 | 已有结果 | 能说明的范围 |
| --- | --- | --- |
| 浏览器原型 | 静态资源、设计准则、工作台和资源交互检查通过 | 浏览器中的设计与演练，不是系统安装或桌面 IME |
| Avalonia 离屏真实 UI | 13 类专项及 vex 主流程通过 | 实际 App、控件、VM、布局、焦点事件和工作流；不是所有实体桌面行为 |
| Windows 原生载荷 | NativeAOT 构建、PE CLR 目录为空、运行时验证通过 | 真实可执行文件、资源和隔离配置 |
| Windows 安装器 | 独立生产入口真编译，原生窗口交互和十图比较通过 | 指定语言 / 主题 / DPI 下的夹具，不替代真实覆盖安装与 UAC |
| Linux / macOS | 受控打包边界和资源检查通过，正式原生 runner 成功 | 原生构建和打包，不表示本机已完成人工系统 UI 验收 |
| 正式发布资产 | 五包 + 五 SHA 公开下载并验证通过 | 版本、文件名、唯一性、非空、大小和校验和 |

## 2. 功能与状态验证

1.7.2 收尾重新通过 41 项更新与安装交接场景、157 项表格 / 图片几何断言，以及官网入口、正文选择和更新日志滚动条的真实控件拖动回归。表格检查区分长表压缩与短表自然宽度，覆盖 1380 / 980 窗宽、明暗、阅读 / 源码预览 / 即时编辑及演示。

### 导航、工作台与外观

- 文件目录折叠按路径保存；大纲折叠按文档与标题层级保存，覆盖刷新、新实例、标题行偏移、搜索临时展开及方向键。真实 XML 往返和多实例部分更新通过。
- 32px 标题栏、58px 工作栏、248px 菜单，八布局、格式工具、窄窗溢出与四语宽度通过。大纲、信息、章节详情共用右辅助栏，页签持久化。
- 章节改名、正文、升降级、顺序、拖动、删除确认、F2、CRLF 和跨布局 / 分离窗口共享撤销通过。保存及关闭前提交章节表单。
- 16 配色、27 排版独立预览、推荐 / 全部、当前标记、键盘浏览不应用、选择后保留面板通过。覆盖 800×480、1024×768、1440×1000 和四语。
- 16 × 2 × 27 共 864 组原生资源对比度检查覆盖正文、链接、引用和六级标题。这是资源矩阵，不是 864 张逐像素截图。标题间距、行高、引用装饰、段落留白、中文无衬线回退及内容自适应表格有专项检查。
- 32 组配色 / 明暗按钮状态、危险动作对比度和紧凑鸣谢布局检查通过。外观菜单与排版面板的后台语言通知转 UI 线程，离树后不执行过期重建；四语切换后保留文件、筛选、正文和撤销。

### 数据保护

- 真实独占文件锁使保存失败，正文、未保存状态与历史保持；解锁后重试保存最新内容。导出失败及取消通过可控服务验证独立重试，成功导出不标记 Markdown 已保存。
- 真实文件监听、比较取消、显式保留、载入外部内容和撤销通过。恢复先预览来源与全文，处理原文未保存保护后创建独立未保存文档。
- 草稿按进程隔离；目录写入失败保留待写内容，支持重试；新磁盘内容不丢旧草稿；损坏和有效草稿共存时保留原数据。保存 / 草稿失败阻止关闭，成功保留草稿后才退出。

### 动效与位置恢复

- 140 / 220 / 260ms 令牌、cubic(.2,.8,.2,1)、菜单纯淡入、选择面板 -4px / .985、对话框 9px / .99 的入场参数通过。真实偏好浮层中间帧和最终不透明状态已检查，动画过程中布局边界不变。
- 运行中关闭动效恢复基础值，重开直接显示；20 次显隐后任务结束且移出视觉树，解除订阅。
- 演示回归用独立生成的 150 节、五个 HTML 表格文档，三轮深入滚动、正文 / 导图切换、退出后保持块与块内位置，离屏块继续虚拟化。此项不再依赖私有样本路径；其他少数历史专项仍有样本前置条件，见开发指南。

应用专项为 prototype-appearance、prototype-chrome、protection、settings-real-ui、desktop-parity、workspace、workbench、editing-tools、layout、locale、preferences、presentation、motion，并通过完整 vex 主流程；最终补丁复核了工作区、布局、保护和主流程。

## 3. Windows 安装器视觉与维护

真实中英文 × 明暗，以及维护、缺失程序、迁移、未知位置、多安装范围交互矩阵通过。中文 / 空格路径下生产入口真编译通过；夹具只复制测试载荷，不在开发机执行真实 Vex 安装或卸载。

中文原型的初始、展开选项、进度、完成、维护 × 明暗，共十图，1.7.2 修复后重新捕获比较：原始 RGB **98.03%～99.15%**；1px 字体栅格容差后 **98.61%～99.46%**。没有增加遮罩或降低 98% 阈值。许可完整原文和英文没有对应原型，不计入该图像分数，另有交互检查。

长路径省略与完整提示、维护详情、迁移 / 未知位置主操作、缺失程序禁用打开均有专项。维护纯逻辑 171 项和迁移 49 项覆盖精确注册身份、卸载器边界、取消、UAC 拒绝、残留注册、路径重叠及配置恢复。多 DPI、真实全用户迁移 / 卸载和系统窗口仍需对应实机检查。评分公式及夹具边界见 [安装与发布](安装与发布.md)。

## 4. 性能与稳定性

1.7.0 使用 CodeWF.Avalonia 12.1.4.34，Windows Release 托管 Headless + Skia 连续三轮；同机存在 NativeAOT 编译负载。脚本自生成文档，中文输入每文档 30 次，计时包含输入派发和离屏渲染 tick，全部字符同步及原有图片 / 任务断言通过。

| 指标 | 三轮中位数（最小～最大），毫秒 |
| --- | ---: |
| 12 节、约 3 千字符即时打开 | 578.1（575.0～643.5） |
| 100 节、约 2.6 万字符即时打开 | 439.2（339.3～502.0） |
| 长文首次阅读，含 PNG 编码 | 209.8（183.9～224.1） |
| 长文切源码 | 56.9（48.8～59.9） |
| 长文返回即时 | 22.4（20.6～24.5） |
| 小文输入中位数 / P95 | 7.0（6.2～7.7）/ 35.9（25.6～36.5） |
| 长文输入中位数 / P95 | 12.5（11.1～13.5）/ 37.4（34.3～41.5） |

小文先运行，首次输入 / JIT 峰值为 272.9～369.6ms；长文最慢输入为 34.4～46.5ms。不能据此认为长文越大越快，也不能宣称所有输入均在 16ms 内、真实屏幕帧率或正式 AOT 桌面冷启动已达某值。历史版本三轮表不再复制进当前基线，避免跨依赖、运行时和负载比较。

长文、公式、长代码、图片、宽表格、八布局往返、导图平移 / 缩放、多窗口替换及并发只读曾有压力回归；样本和宿主各有前置条件。重复验证应记录原文哈希、逐组合结果、物化控件数量和内存，不能以少数轮次证明无限规模稳定。方法、性能归因及虚拟化首次构造边界见 [开发与验证](开发与验证.md)。

## 6. 自研库验证边界

当前四个直接 CodeWF.Avalonia 依赖固定为正式 NuGet 版本 **12.1.4.35**，没有跨仓项目引用。开发时先将自研包放到 `E:/github/temp_nugets` 供 Vex 还原验证；库版本与标签发布后，正式发布还原同版本线上包。

本文只记录 Vex 实际使用的功能和验证结果。应用的通过结果不等同于全部依赖库、全部控件或所有平台行为均已验证。

## 7. 仍需验证或改进

| 范围 | 当前边界 |
| --- | --- |
| 完整视觉一致性 | 尚无全应用、全平台逐场景 ≥98% 的量化证据；Windows 十图分数有明确范围 |
| 真实桌面 | 中文 IME 组合、多 DPI、跨屏、多显示器、读屏与系统焦点需补实机 |
| macOS / Linux 安装 | Finder / Gatekeeper / Developer ID / 公证、Retina，Linux 软件管理器、权限与桌面集成未全部人工实机验收 |
| 文件安全 | 手动保存仍是直接异步写入；配置只有进程内锁；草稿不代替正式备份 |
| Markdown 与导出 | 浏览器 22 类 Mermaid 模板通过不代表应用或 PDF / PNG / Word 全语法等价；复杂公式、SVG、字体与分页逐格式核验 |
| MCP | UI 主题 schema 尚未覆盖全部 16 配色，布局仍为布尔接口；真实客户端逐个联调；Token 未使用系统凭据库 |
| 性能 | 首次 JIT、控件构造和复杂块成本仍存在；尚无所有平台正式 AOT 桌面冷启动 / FPS 基准 |
| 可复现测试 | 少数历史压力和 HTML 表格模式仍依赖私有样本，通用模式与限制在开发指南明确 |

下一次补验优先选择真实 IME / DPI、macOS 挂载和 Linux 软件管理器，以及完整应用同状态视觉对照；结果继续更新本文，不新增逐修复流水文档。
