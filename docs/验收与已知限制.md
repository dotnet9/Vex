## 1. 当前交付结论

v1.13.0 已由正式流水线构建并发布，五平台安装包与绿色压缩包共十件，连同十份 `.sha256` 摘要公开在 GitHub Release（证据见 §5）。正式发布在原生 runner 上完成 NativeAOT 构建，`win-x64` 任务的「验证正式 Windows 原生载荷」步成功，即 `--verify-runtime` 的版本、四语、对话框资源、六份演示文档、22 类 Mermaid 出图、隔离配置与 PE CLR 目录为空检查在 CI 复证。本机未执行真实产品覆盖安装或卸载。

应用已接入 9 配色、13 套正文排版、四语（zh-CN / zh-Hant / en-US / ja-JP）、原型工作台与八布局、持久化导航、文件保护、辅助面板、动效与圆角档位、三处悬浮缩放坞，以及下沉到库内共享 `SegmentedPanel` 的全部分段控件。视觉量化证据只覆盖两处：Windows 安装器中文十图（历史记录，§3）与工作台十场景原型像素对照（§7 的 94.01%）；不能据此宣称全应用或全平台已达某个像素一致度。

### 导航、工作台与外观

- 文件目录折叠按路径保存；大纲折叠按文档与标题层级保存，覆盖刷新、新实例、标题行偏移、搜索临时展开及方向键。真实 XML 往返和多实例部分更新通过。
- 标题栏 33px（`MainWindow.axaml` 的 `TitleBarHeight`，与原型 `--app-titlebar-height: 33px` 同源）、菜单浮层 248px，一级与级联同宽（与原型 `--title-menu-width` 和 `.menu-flyout` 的 `min-width: 248px` 同源）。八布局、格式工具、窄窗溢出与四语宽度通过。右辅助栏按原型收敛为单一大纲面板，文章信息改由「属性…」对话框承载，章节详情悬浮于导图右上角。**应用里没有「工作栏」这个控件，旧文档写的 58px 工作栏是虚构描述，已在本文与详细设计中删除。**
- 章节改名、正文、升降级、顺序、拖动、删除确认、F2、CRLF 和跨布局 / 分离窗口共享撤销通过。保存及关闭前提交章节表单。
- 9 配色、12 排版独立预览、推荐 / 全部、当前标记、键盘浏览不应用、选择后保留面板通过。排版卡度量按 CDP 视口仿真实测：原生 160×151，原型 160.5×150.5，网格宽 682、四列、共 12 张，密度行几何一致；交接文档里「162px vs 原型 151px」的旧说法与实测相反，不成立。覆盖 800×480、1024×768、1440×1000 和四语。
- 对比度覆盖当日实测为三族：按钮状态 **108** 项（主要 / 危险 × 9 配色 × 明暗 × 常态 / 悬浮 / 按下）、文件标题与选中卡片 **18** 项（9 配色 × 明暗）、更新标签胶囊 **36** 项（四语 × 明暗及浅色列）。阈值 4.5，逐条打印前景 / 背景与实际比值。旧的「9 × 2 × 12 共 216 组」矩阵口径已不存在，不再引用。标题间距、行高、引用装饰、段落留白、中文无衬线回退及内容自适应表格有专项检查。
- 外观菜单与排版面板的后台语言通知转 UI 线程，离树后不执行过期重建；四语切换后保留文件、筛选、正文和撤销。代码里的界面文案已退回 JSON 资源并由 T4 生成强类型键，语言词表（更新日志标签）同样由 `zh-CN.json` 生成 `ReleaseTags.cs`，源码不再出现中文字面量常量。

### 数据保护

- 真实独占文件锁使保存失败，正文、未保存状态与历史保持；解锁后重试保存最新内容。导出失败及取消通过可控服务验证独立重试，成功导出不标记 Markdown 已保存。
- 真实文件监听下，自动保存开启时以磁盘为唯一真值：外部修改静默载入，载入前内容可撤销找回，不再出现「请先比较」类阻断；防抖窗口内仍有未落盘键入时同样静默载入并以 toast 告知。
- 草稿按进程隔离；目录写入失败保留待写内容，支持重试；新磁盘内容不丢旧草稿；损坏和有效草稿共存时保留原数据。保存 / 草稿失败阻止关闭，成功保留草稿后才退出。

### 动效与位置恢复

- 动效令牌与入场参数（菜单纯淡入、选择面板位移、对话框浮起）由动效档位驱动过渡时长，档位切换即时生效；真实偏好浮层中间帧与最终不透明状态已检查，动画过程中布局边界不变。
- 运行中关闭动效恢复基础值，重开直接显示；20 次显隐后任务结束且移出视觉树，解除订阅。
- 演示回归用独立生成的 150 节、五个 HTML 表格文档，三轮深入滚动、正文 / 导图切换、退出后保持块与块内位置，离屏块继续虚拟化。此项不依赖私有样本路径；少数历史压力专项仍有样本前置条件，见开发指南。

## 3. Windows 安装器视觉与维护

`windows-installer-contract` 当日在 `7b467fd` 全绿，两个任务：**独立安装器契约真编译**（校验快照与两语资源完整、中文与空格路径下生产入口真编译、跨安装范围迁移脚本逐条断言，逐条计数随 `receipt.json` / `assertions.txt` 上传）与**安装器原生中英文与浅深色回归**（`new` / `maintenance` / `current` / `unknown` / `multiple` / `migration` 六类夹具 × 中英 × 明暗的真实窗口交互矩阵）。夹具只复制测试载荷，不在 runner 或开发机执行真实 Vex 安装或卸载；纯逻辑夹具证明预处理结果不含注册表、进程或外部调用，且 `InitializeSetup` 无条件返回 `False`。

十图像素比较由 `scripts/installer/tests/compare_vex_visual.py` 承担，阈值 98%，只在显式传入 `-ReferenceDirectory` 时执行；CI 的调用不带该参数，所以**逐图像分数目前是按需本地步骤，不是默认门禁**。最近一次实测记录属于 1.7.2：中文初始、展开选项、进度、完成、维护 × 明暗共十图，原始 RGB **98.03%～99.15%**，1px 字体栅格容差后 **98.61%～99.46%**，未加遮罩也未降低阈值；该组数字未在 1.13.0 复测，且本机无 ISCC，复现需在有 Inno 编译器的机器上执行。许可完整原文与英文没有对应原型图，不计入该分数，另有交互检查。

维护纯逻辑与迁移的 171 / 49 项同样是 1.7.2 历史记录：`verify_maintenance_logic.py` 目前只在本地按 `安装与发布` 的说明执行（每具执行夹具 57 项断言），未进入工作流；迁移断言在 CI 逐条打印并上传收据。长路径省略与完整提示、维护详情、迁移 / 未知位置主操作、缺失程序禁用打开均有专项。多 DPI、真实全用户迁移 / 卸载和系统窗口仍需对应实机检查。评分公式及夹具边界见 [安装与发布](安装与发布.md)。

内嵌更新日志与 `docs/更新日志.md` 逐字同步属于契约测试范围：当日 CI 夹具日志已确认 `V1.13.0 2026-10-27` 各小节标题、标签与发布日期收尾干净，正文里不残留 `[标签]-` 写法，全角括号不混进标题。改动日志文档必须同步再生 `Vex.Setup.iss` 的 `VChangelogEmbedded`，否则安装器契约测试红。

## 8. 门禁可信度

两处门禁写法上的隐患已在本批次定位并修正，记录在此以免后续再踩：

- **隐式退出码传播随宿主版本而变。** 本机 PowerShell 7.6 实测：Actions 把 `shell: pwsh` 的整步交给 `pwsh -command ". '<脚本>'"` 点执行，这种形状下脚本最后一条原生命令返回 7 时子进程仍退 0，补一句 `exit $LASTEXITCODE` 才非 0；而 runner 的 pwsh 不是这个行为——历史上裸 `dotnet test` 步骤确实把流水线判红过（库仓 run 40440121548）。两边只有「自己起进程、自己读 `ExitCode`」在哪一版都成立，库仓「运行冒烟演示」步据此改为 `ProcessStartInfo` + `WaitForExit` + 显式判定退出码，并把输出重定向后写回日志，失败可定位。该步上一版红的是参数不是冒烟：`--smoke` 从启动到退出实测 91.2 秒（退出码 0），上限却按日志时间戳差写成 60 秒；现给 240 秒。
- **验证工程的源文件清单漂移。** `scripts/update-verification` 与 `scripts/ui-verification` 各自手工挑选 Vex 源文件编译，主工程能过不代表它们能过；新增类型（更新日志分节与标签词表）落地时若忘了补 `<Compile>`，只在 CI 以 `CS0246` 暴露。同日性能脚本的三条断言仍按旧契约写，隐藏正文列不再抢跑解析后必然崩。两者都按当前契约改正，本地跑通后推送，CI 绿。

同类风险：任何只打印 `PASS` 而不设置非零退出码的步骤都必须用退出码判定；用日志时间戳差估超时是错误来源，必须实测。
