# 工作区与交互

这里维护桌面原型的交互目标；当前应用操作见 [快速开始](../快速开始.md)。原型和应用存在差异时，以 [验收记录](../验收与已知限制.md) 标明状态，不将原型动作计为已经实现。

## 文档与视图

一个进程编辑一份当前文档。源码、即时编辑、阅读、导图及其组合共享 Markdown、章节位置和编辑历史；切换文件时，辅助面板与独立视图不得残留上一份文档的内容。

八种布局为：即时编辑、源码、阅读、导图、源码＋阅读、源码＋导图、即时编辑＋导图、三视图。原型沿用顶部中央布局选择器、左侧文件导航、右侧辅助面板和底部状态栏。变窄时压缩或覆盖辅助面板，保留桌面交互，不切换为其他设备产品。

大纲、文章信息和章节详情共用右侧辅助面板，默认收起。章节标题、正文、层级、顺序、删除和定位都作用于当前文档；阅读与演示只提供查看、跳转和复制。

## 菜单与元素操作

保留文件、编辑、段落、格式、视图、工具、帮助七组菜单。常用命令直接展示，表格行列、Mermaid 分类和文档操作按职责归组。子菜单在边缘避让，支持方向键、Home / End、Enter、逐级 Escape 和点击外部关闭。

标题栏菜单、级联子菜单以及外观、语言弹出面板统一使用“文件”菜单的 248px 宽度，由 `--title-menu-width` 控制。长菜单文字允许换行，快捷键和展开箭头保留独立位置；靠近窗口边缘时继续避让。

正文与源码支持右键和 Shift+F10。链接、图片、代码、公式、图表、表格和文字选区使用各自的操作项；只读区域禁用修改。异步粘贴、图片选择或确认返回时，应核对原文档及选区仍有效，不能把旧命令应用到另一份文档。中文输入法组词期间不触发破坏候选状态的快捷键。

## 表格列宽

表格按实际内容分配列宽，禁止默认等宽或将每列固定为 `100% / 列数`。短标签列收窄，职责、解释等长内容列获得更多空间。表头、正文、行内代码和单元格内的换行都参与宽度判断。

浏览器采用自动表格布局与内容宽度，通常无需把短表格拉满正文。超过可用空间时可换行或在表格容器中横向滚动，不挤压整个工作区。验收至少覆盖“负责方 / 职责 / 示例”三列，确认第一列不因等分产生大片留白；三视图、深浅模式、长链接和中文长句均须可读。

表格行列操作保留表头与至少一列，结构修改可一次撤销；不提供 Markdown 本身不支持的合并单元格。

## 保存、偏好与更新

未保存、保存中、已保存、保存失败应有明确文字。失败后保留内容，允许重试或保存副本；取消不能显示成功。正文自动保存与偏好持久化是不同开关。

原型中的偏好有效改动立即保留；MCP 开关及状态用于交互评审。当前应用 MCP 配置仍以保存后生效的实际实现为准。常规文件对话框、浏览器下载和系统剪贴板受浏览器能力约束。

原型保留检查、发现版本、下载中、可安装、失败重试等更新状态；安装器交接、SHA256 校验和关闭时机必须在实际应用与安装包中验证。

## 外观与引导

明暗模式、配色、正文排版独立选择，保持原文、选区、滚动与撤销历史。风格共用语义资源 Key，只改变资源值；合并列表见 [外观资源](../resources/外观资源.md)。

桌面原型的明暗与配色只作用于软件窗口、菜单及对话框。窗口外的展示背景固定为中性浅灰 `#EAECEA`，不随明暗、配色或系统主题变化。

标题栏的外观、语言入口与窗口操作按钮共用水平中心线。小窗口中的配色、排版列表应可滚动到末项；不能因方案增加而把按钮裁到视口外。

正文排版以预览卡片网格展示，每张卡片使用对应风格渲染同一段标题、正文与引用，直接比较字形、间距、装饰和色彩，无需先切换才能查看效果。卡片区竖向滚动，标题与紧凑布局开关固定；点击卡片应用，方向键与 Home / End 只移动焦点，Enter 应用。选择后保持列表滚动位置，各卡片继续显示自身风格。

导图节点先展示章节标题；“文档 / H2”等辅助类型在标题旁用小号、低强调文字显示，不单独占据标题上方一行。折叠按钮、重命名与章节操作保留。图表标题、轴标签和节点标签的可读性规则见 [Markdown 图表](../Markdown图表.md)。

新手引导从帮助菜单主动打开。围绕一篇临时文章演练写作、结构、布局、排版与分享；完成或跳过后恢复原文、历史、布局和偏好。演练中的保存必须写副本，安装、外站发布和系统操作不能假装真实完成。原型与应用当前引导步骤不同，分别验收。
