# 原型设计与评审

原型集中在仓库 `design/`，用于确认桌面布局、内容呈现和交互。保留既有工作区、菜单、导图、偏好、更新及引导流程，整合配色与排版资源。应用仅面向 Windows、Linux、macOS。

后续原型修改统一遵循 [原型设计准则](../../design/原型设计准则.md)，具体场景从 [评审清单](../../design/Usability-Review.html) 进入。

## 打开方式

在仓库根目录执行：

```powershell
node design/scripts/preview.cjs
```

访问 [原型导航](http://127.0.0.1:4317/design/)。仅需 Node.js，服务只监听本机回环地址；请求版本和内置文档时读取本仓库的配置与文档，无需其他源码仓库或第三方 Node 包。

也可执行 `node design/scripts/sync.cjs`，再直接打开 [index.html](../../design/index.html)。复制原型供离线评审时，保留整个 `design` 目录；公式、图表、导图和代码字体均为本地依赖。直接打开页面后修改源文档，需重新同步。

## 场景参数

工作区支持 `platform=windows|linux|macos`、`theme=light|dark|system`、`palette=<配色Key>`、`typography=<排版Key>`、`layout=instant|source|read|map|source-render|source-map|instant-map|three`、`lang=zh-CN|zh-Hant|en-US|ja-JP`。`source-read` 兼容为 `source-render`。

`scenario=empty|new|no-headings|long-document|long-files|save-error|export-error|external-change|draft|guide` 演示空内容、长文、深目录、失败、恢复和引导；`preview=1` 隔离浏览器本地偏好，适合对照截图。窗口缩窄仍使用桌面工作区。

安装器支持 `scenario=installed|error|installing`、`theme=light|dark`；`scenario=installing&progress=46` 固定进度供查看。点击安装后的进度和系统授权是演示；不会创建真实安装包、修改默认程序或卸载软件。

## 资源与实现边界

原型的 16 套配色、27 套排版保留全部设计，并补入当前应用资源。默认沿用纸白与品牌墨青；文字强调、装饰与实底控件分开配色，对比度在共享适配层校正。相同原始键但不同样式已分配独立标识，见 [外观资源映射](../resources/外观资源.md)。

`assets/project-info.js` 和 `assets/generated/documents-data.js` 从本仓库生成；当前版本来自 `Directory.Build.props`。内置更新日志、鸣谢及产品链接不得引用另一处实现或无关版本。

浏览器中的文件、草稿、MCP、更新、安装与导出状态属于原型能力。浏览器原型不等同于 Avalonia 控件，不证明中文输入法、大文件、NativeAOT、系统文件关联或安装升级已经通过。正式产物以 [发布矩阵](../RELEASE.md) 和对应系统验收为准。
