# 原型与 NativeAOT 复核

2026-10-16，版本 1.5.8：配置改为一次读取快照、批量保存，补齐工作区、源码预览、脑图和编辑模式等十二项偏好持久化；部分更新仍读取最新磁盘配置，保留其他实例的设置、外部键与自定义 XML 节。即时编辑器一次载入正文和图片基址，同一正文切换到其他目录也更新图片路径并保留选区；阅读预览继续同步预热与即时图片刷新。文件打开、文件树和最近记录等身份比较采用 Windows 忽略大小写、其他平台区分大小写的规则，工作区状态与即时图片基址按精确路径继续同步。

对话框主按钮使用共享主题的主色、前景和交互令牌，删除按钮使用 Semi 危险色与浅底反馈。托管真实浮层与单文件原型分别通过八色浅深组合、普通／悬停／按下共 96 种状态的文字对比度检查；按下后移出再释放，不执行更新或删除。路径身份修复后的完整托管界面回归通过 638 项断言，设置往返、相同正文跨目录和预览权限回归通过。Windows 当前文件系统不区分大小写，双真实文件分支明确跳过；真实状态和同一编辑器的精确路径、选区断言仍执行，不将其称为 Linux 文件系统实测。

路径身份修复后的最终源码通过仓库正式脚本重新完成 Windows x64 NativeAOT 发布，正式 EXE 四语及隔离偏好自检通过，PE 的 CLR 数据目录为空。独立界面验证器重新发布为 NativeAOT 后实际运行，638 项断言全部通过；README 与本页七张截图已替换为该次原生离屏图，并逐张查看。发布使用仓库外的本地 NuGet 源恢复 CodeWF.Avalonia 12.1.4.25 与 Toolkit.Files 1.0.0.25，本地源和缓存路径不进入仓库。

性能验证器另行以 NativeAOT 发布后实际运行，正文与路径同步、远程图片刷新及源码任务编辑断言全部通过，PE 的 CLR 数据目录为空。该次功能运行受同机编译负载影响，计时不纳入性能结论；不把原生单轮和托管旧新三轮混为同一组性能对比。

同一正式 EXE 经无符号暂存目录按既有 Inno Setup 脚本生成 Windows 安装包和 SHA-256，未执行安装器或注册系统文件关联。ILC 仍报告既有 Prism `DialogWindow` 缺少反射绑定方法的警告；Vex 实际使用 Ursa 浮层，本轮覆盖该实际通路，不将结果扩展到未使用的 Prism 对话窗口。

同机旧、新各三轮交错复测中，配置读取二十次的中位数由 36.9 ms 降至 11.3 ms，部分更新二十次由 528.9 ms 降至 36.1 ms，100 节文档即时打开由 5643.5 ms 降至 3899.1 ms。小文档首次阅读与初始化耗时区间仍有重叠；同机存在其他构建负载，样本量有限。这是包含同步 PNG 编码的托管离屏测量，完整范围、输入与限制见[性能复测记录](../scripts/performance-verification/README.md)。阅读虚拟化仍先构造全文控件，首次构造成本需要后续按需块工厂继续处理。

2026-10-16，版本 1.5.7：修复全局语言改变后标题栏选择仍停留旧语言的问题，工作区通知返回 UI 线程。后台切语回归保持真正的 Markdown 阅读视图打开，使用同一个语言下拉反向切回，覆盖简体、英文、繁体和日文。CodeWF.Avalonia 12.1.4.24 修复查看器菜单的后台线程更新及只读表格外框的多余空白；表格检查改为仅检查可见视图，分别核对即时编辑和阅读模式。文件关联补充三种 Markdown 扩展名和含空格路径的启动、拖放解析，不实际注册系统关联。

逐图检查另外发现英文侧栏仍残留“1天前”：翻译资源已有，但文件快照缓存了创建时的文案。文件模型现在只对时间标签发布变更，语言回调在 UI 线程重新格式化时间；文件树对象、选中节点、过滤和未保存 Markdown 保持原状态。回归固定样例修改时间，并在四语后台切换时断言同一个实际时间标签和树节点。即时编辑与阅读表格另外滚入视口截图，逐图确认自然列宽与外框没有多余空白。

1.5.7 使用官方 NuGet 源及独立包缓存完成正式 Windows NativeAOT 发布；正式 EXE 隔离自检、PE 的空 CLR 目录检查、独立 NativeAOT UI 全套回归及 EXE 安装器生成均通过。上述四语后台切换、同一个实际下拉反向同步、原有时间标签更新，以及即时编辑与阅读的可见表格宽度检查，均在最终原生验证器执行。README 与本页截图已替换为本轮原生离屏图，并逐张查看；没有执行安装器或系统文件关联注册。
