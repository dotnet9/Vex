# 原型与 NativeAOT 复核

在 1.5.5 的产品实现上复核编辑、阅读、导图及单文件离线原型，使用 CodeWF.Avalonia 12.1.4.20 和 Toolkit 1.0.0.19。

- 用仅含 nuget.org 的仓库外配置及全新缓存恢复依赖，执行 `scripts/publish.ps1 -RuntimeIdentifier win-x64`，NativeAOT 发布成功。
- 将 `scripts/ui-verification` 另行发布为 NativeAOT 并实际运行，369 项断言通过。覆盖五份 Markdown 文件切换与保存、三视图、八套配色各浅深模式、980 × 640 布局、文件树、表格自然列宽、标题栏与内容分隔、完整引导和用户偏好恢复。
- 同一个关于浮层打开期间切换简体、繁体、英文、日文，校验实际应用版本、编译时间与平台，生成四语原生截图。
- 更新状态机 16 个受控场景通过；四组原型浏览器审计通过。文件关联脚本覆盖 `.md`、`.markdown`、`.mdown` 的图标、候选程序和右键入口，复核期间未修改用户默认程序。
- Windows EXE 安装器及 SHA256 已本机生成。安装包结构回归覆盖标准 macOS Resources、语言和帮助文档、Linux 桌面入口与图标、调试符号剔除及失败传播；五平台资产门禁拒绝缺少校验文件和便携压缩包。

![原生关于界面](media/vex-native-about.png)

锁屏期间的复核采用无头浏览器和真实应用离屏渲染，没有做桌面键鼠验收。输入法、多 DPI、系统文件关联实际注册和其他操作系统仍需专项验证。NativeAOT 构建保留依赖库的裁剪 / AOT 警告，不能据此声称所有代码分支均已覆盖。
