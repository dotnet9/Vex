# 原型与 NativeAOT 复核

2026-10-16，版本 1.5.7：修复全局语言改变后标题栏选择仍停留旧语言的问题，工作区通知返回 UI 线程。后台切语回归保持真正的 Markdown 阅读视图打开，使用同一个语言下拉反向切回，覆盖简体、英文、繁体和日文。CodeWF.Avalonia 12.1.4.24 修复查看器菜单的后台线程更新及只读表格外框的多余空白；表格检查改为仅检查可见视图，分别核对即时编辑和阅读模式。文件关联补充三种 Markdown 扩展名和含空格路径的启动、拖放解析，不实际注册系统关联。

逐图检查另外发现英文侧栏仍残留“1天前”：翻译资源已有，但文件快照缓存了创建时的文案。文件模型现在只对时间标签发布变更，语言回调在 UI 线程重新格式化时间；文件树对象、选中节点、过滤和未保存 Markdown 保持原状态。回归固定样例修改时间，并在四语后台切换时断言同一个实际时间标签和树节点。即时编辑与阅读表格另外滚入视口截图，逐图确认自然列宽与外框没有多余空白。

1.5.7 使用官方 NuGet 源及独立包缓存完成正式 Windows NativeAOT 发布；正式 EXE 隔离自检、PE 的空 CLR 目录检查、独立 NativeAOT UI 全套回归及 EXE 安装器生成均通过。上述四语后台切换、同一个实际下拉反向同步、原有时间标签更新，以及即时编辑与阅读的可见表格宽度检查，均在最终原生验证器执行。README 与本页截图已替换为本轮原生离屏图，并逐张查看；没有执行安装器或系统文件关联注册。

2026-10-16，版本 1.5.6 补充：修复全局语言切换与第三方主题接线。验证器直接修改唯一 I18nManager，在同一个已打开的 Semi TextBox 上反复展开实际菜单，检查简体、英文、繁体和日文复制、粘贴文案及 Ursa 对话框资源；宿主设置同键文案后继续回切，覆盖保持生效。主题字典保存在主题自身资源中，事件切换在 UI 线程执行。

本轮使用官方 NuGet 源和独立包缓存，重新通过正式 Windows NativeAOT、正式 EXE 隔离自检、原生 UI 全套回归及 EXE 安装器生成，PE 的 CLR 目录为空。另以同一产品源码追加托管最小窗口检查：980×640 下四语工具栏所有按钮、关于内容视口、顶部更新按钮及滚动到底部后的关闭按钮均在可用区域内；编辑偏好的长文档滚动、Markdown 自然表格列宽和五步引导继续通过。新增最小窗口断言属于托管验证，原生结果来自此前已完成的完整验证器，不将二者混称。

- 单文件离线原型与标题栏交互同步，具备桌面窗框；浏览器审计实际点击语言菜单、八色点与三态模式，固定关于样例时间不覆盖正式程序编译时间。
