# Vex 快速开始

Vex（维刻）是一个基于 .NET 10 与 Avalonia 的 Markdown 编辑器。维刻 Vex · 写下想法，看见脉络。

## 基础操作

1. 通过“文件 / 新建”创建空白 Markdown 文档。
2. 通过“文件 / 打开”打开单个 Markdown 文件。
3. 通过“文件 / 打开文件夹”加载文件列表；直接打开单个文件时，也会自动加载同目录 Markdown 文件。
4. 编辑视图默认即时渲染：点击排版后的正文直接写作；`Ctrl+Enter` 完成、`Esc` 取消本次块编辑。代码块编辑时在下方修改代码类型。需要完整 Markdown 时切换“源码”。
5. 从网页复制内容后粘贴到中间编辑区，Vex 会优先读取剪贴板 HTML 并转为 Markdown；普通文本粘贴仍会照常回落。
6. 通过标题栏的三态主题按钮和八个配色色点调整界面；正文右上角打开 18 套排版的预览卡片。
7. 通过“文件 / 导出”导出 HTML、PDF、PNG 或 Word（.docx）；PDF、PNG 和 Word 会处理本地、`data:image`、HTTP(S)、SVG/GIF/WebP 图片，PDF 正文可选择和复制，PDF 和 Word 也会把图片嵌入文件，离线发送后仍可查看。
8. 通过“工具 / 复制到公众号”“复制到知乎”“复制到稀土掘金”把当前 Markdown 写入富 HTML 剪贴板；粘贴到对应网页编辑器时会按当前排版主题渲染。
9. 使用 `Ctrl+F` 查找、`Ctrl+H` 替换；查找和替换输入框限制为单行，避免超长文本撑乱布局。
10. 切换“阅读”检查正文，切换“导图”梳理章节。选中标题可改标题及正文；双击或 F2 改标题，Enter 新增同级、Tab 新增子章节。工具栏与详情支持调整层级、顺序及删除；拖动携带整章和子章，操作可撤销。
11. 从“布局”选择八种组合，连续点击比较效果；布局、排版面板均保持展开，按 Esc 或点击外部关闭。需要多屏时把视图分到独立窗口。所有窗口共用当前文档；在文件页切换文档会同时替换各视图。
12. 从“帮助 / 新手引导”进入六步演练；完成或跳过后恢复原文、编辑历史、布局和原独立窗口。

## 演示文档

点击工具栏“演示”或按 `F6`，在“正文 / 文档大纲 / 导图”间切换。正文按标题分节，左右键或 `PageUp / PageDown` 翻节，长章节可继续滚动，`A− / A+` 调整字号。大纲点击章节进入正文；导图可平移、缩放及收折，双击节点或选中后按 Enter 跳转正文。导图模式下 `+ / −` 缩放。

`D / O / M` 切换正文、大纲、导图，`Esc` 或再次按 `F6` 退出，恢复进入前的布局与位置。演示时隐藏导图编辑操作，不修改文档。
