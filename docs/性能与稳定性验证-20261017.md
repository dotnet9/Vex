## 发现与修复

- 更新日志拖动崩溃：Windows Application 日志记录 `Infinite layout loop detected`。虚拟面板回收时把不含 Margin 的 Bounds 高度写回含 Margin 的尺寸缓存，导致布局反复补偿。改为保留完整测量尺寸，并覆盖真实滑块拖动回归。
- 即时编辑拖选：初次按下在只读预览上，编辑 TextBox 没有收到起始事件。补齐首次拖选、跨段正反向选区、复制、输入替换与共享撤销。
- 脚注与链接定义：Markdig 将合成定义节点放到其他位置，其 Span 不能作为顺序切片边界。排除合成节点切片，定义原文仍保留在块间文本中；覆盖 LF、CRLF 和只有定义的文档。
- Mermaid 生命周期：每次挂载累积卸载回调，重复取消已释放的 CancellationTokenSource。改为统一图块生命周期管理，卸载时退订主题和尺寸事件，再次挂载可重新渲染。
- 阅读视图：原先先构造全文表格、高亮和公式控件，再由虚拟面板移出视口；1.16 MB 样本曾占用约 6.3 GiB 并长时间阻塞。改为轻量块槽位，进入视口才创建实际内容，离开时释放绑定与子树。
- 大导图：保留完整文档模型及节点几何，只为视口和缓冲区附近建立卡片及连线，平移时按区域刷新。
- 长代码：逐 token 修改已绑定的 Inlines 会反复拼接全文。短代码先构造集合再赋值，长代码改用 TextLayout 样式区间，减少逻辑树及主题匹配开销，保留高亮、行号和选择。
- 即时编辑几何：输入层不再覆盖代码横向滑块，并为轨道预留空间；多行段落保留与预览相同的软换行，避免首次点击重排。
- 文件切换：读取结果带请求版本，较早结果不能覆盖最后一次选择；重新编码、最近文件和 MCP 打开复用此检查。快速打开接入未保存确认。

## 压力验证

性能采样包为 `12.1.4.28-vex.19`。vex.21 补充代码横向滚动的命中与编辑层裁剪修正，并重跑两轮全部压力组合；这次与 NativeAOT 编译同时进行，只作稳定性检查，不用于耗时对比。最终 vex.22 再修正多行段落首次点击时的软换行，单独覆盖真实鼠标选择、行数和文字起点回归。共享库均打包到 `D:\github\temp_nugets`，业务通过 NuGet 安装，没有跨仓 ProjectReference。

环境为 Windows Release net10.0、Avalonia.Headless + Skia。每个指针步包含输入、布局和离屏渲染工作，不是实体桌面 FPS；以下为同一进程热切换过程，也不是应用冷启动。

## HTML 表格与阅读恢复复验（vex.25）

正式桌面检查发现 RELAP 的五张 HTML 表格显示成了标签原文；最大化滚动到第 4.9 节后进入导图演示，退出也曾错位至第 4.26 节。两项均作为真实缺陷补充到验证中，不能用先前的短文档断言代替。

现在完整 Markdown 包注册 HTML 表格渲染，复用已有转换器与原生表格，不改写文件；保留行内格式、实体、换行、列表文字和代码。暂不支持合并单元格、嵌套表格及 HTML 百分比列宽，这些复杂表格保留原文回落。Lite 仍是传递依赖，业务未新增直接引用。

恢复错位有两个原因：全文后台模型未到时，宿主就把全文锚点传给演示短节，块序号被夹取；虚拟布局重新量测视口后，一次像素定位也会偏移。现在等待当前全文模型就绪，再按块序号与块内比例校正。真实 RELAP 连续三次深度滚动、正文 / 导图演示与退出，锚点分别为第 108、225、391 块，恢复后的块序号及块内比例一致，且物化块数均少于 100。

共享库全量 **336 项**、应用 **656 项**、工作区 **81 项**、指针 **27 项**、演示专项 **113 项**通过。证据为 `library-reading-html-final.log`、`final-vex25-*.log`、`presentation-vex25.log`。库的混合长文回归同时覆盖 100% / 150% 缩放；演示专项还检查五张实际 HTML 表格均生成四列原生单元格，以及即时编辑全文源码往返保持不变。

## 大纲定位复验（vex.27）

沿用前次会话的表格截图检查，确认纯阅读缺少大纲事件订阅，即时编辑虽物化了目标，却在布局完成前滚动并使用旧 Bounds，画面可能仍停在开头。修复后先完成布局，再按同一目标的实际坐标做有限次滚动校正；超高表格从顶部显示。

## 剩余边界

大幅拖动滚动条首次进入复杂表格或长代码区时，仍可出现数百毫秒，最大化采样个别约 1.8 秒的离屏布局停顿，不能称为性能已完全达标。后续应继续测实体桌面的滚轮连续帧、冷打开和更大单块内容。

多窗口测试共用一个 Headless 屏幕，不等于实际多显示器与跨 DPI 验证。完整中文输入法组合、跨表格字符选择，以及视觉 98% 还原仍需各自验收。正式 NativeAOT 包和桌面操作证据见 `docs/历史原生验收.md`，不能以托管测试结果替代。
