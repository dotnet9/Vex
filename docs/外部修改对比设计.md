# 外部修改与对比设计

实施顺序：先原型（`design/`），验收后桌面端（`src/`）。

## 1. 行为规则

| 前提 | 磁盘文件被外部程序修改时 | 反馈 |
|---|---|---|
| 自动保存开，编辑器无未落盘键入（防抖窗口内无输入） | **静默自动载入**磁盘版本，作为新的编辑内容 | 右下角 toast：*已自动载入外部修改 · {文件名}* |
| 自动保存开，但防抖窗口内尚有未保存键入 | **仍静默自动载入**磁盘版本；未保存键入被丢弃，载入前内容进撤销栈可找回 | 右下角 toast：*外部文件已变更，已自动载入外部版本；未保存的修改已被丢弃，可用撤销找回。*（2026-10-27 用户拍板：自动保存开的语义就是「磁盘为准」，不进对比对话框） |
| 自动保存关 | 不动编辑内容，进入提醒 → 用户点击后打开对比对话框选择 | 见第 2 节 |
| 未命名 / 无路径文档、只读内置文档 | 不监视 | — |
| 本程序自己保存引起的变更 | 不触发（与最后一次已知磁盘状态比对判定） | — |

载入外部版本后可撤销（Ctrl+Z），可随时回到载入前内容。

## 2. 提醒（自动保存关分支）

不做自动弹出的模态框；两处非阻断提醒，用户点击任一入口才打开对比对话框：

1. **状态胶囊**（文档名旁已有）：进入警示态，红描边，文案 `外部已修改 · 点击比较`；忽略前常驻。
2. **toast**（右下角，8 秒自动消失）：*{文件名} 已在磁盘上修改* + 主按钮「比较」。

忽略能力：toast 自动消失即暂不处理；胶囊提供「忽略此次修改」右键项（点击后以当前磁盘内容为新基线，胶囊复位，不载入不覆盖）。

## 3. 对比对话框

标题：*检测到外部修改 · 请先比较*。头部：文件路径 + 「并排 / 统一」视图切换。底部动作：`取消` · `保留当前版本` · `另存当前副本…` · `载入外部版本`（主按钮）。

对比区为真正的差异视图（对齐 GitHub Desktop），不用双栏纯文本：

- **行级差异**：Myers/histogram 算法计算 LCS；等同行折叠——连续超过 8 行未变更折叠为 `⋯ 未更改的 N 行`，可点击展开。
- **配色**：左栏（当前内容）删除行红底、右栏（外部版本）新增行绿底；替换行左右配对展示。
- **词级差异**：替换行内部再做词元级对比（中文字符、英文单词为词元），被删词元深红底、新增词元深绿底，一眼看到行内改动点。
- **行号**：双栏各带行号（统一视图单行号）。
- **双栏滚动同步**；长行不软换行，横向滚动。
- **统一视图**：单栏，`-` 行红、`+` 行绿，供逐行通读。

## 4. 原型改造点（`design/`）

- 触发入口：`文档操作` 菜单末尾加「模拟外部修改（原型演示）」——把当前文档的磁盘副本改写一段（追加/改写一个段落并更新时间戳），用于演示与验收。
- 分支演示依赖原型偏好里的「自动保存」开关，开/关各走一条分支。
- 提醒：状态胶囊警示态 + toast 组件（复用现有 toast，加主按钮形态）。
- 对比对话框：新增组件；diff 用约 120 行自研 JS（Myers 行级 LCS + 词级 LCS + 折叠渲染），不引第三方库。
- 文案键：`ReviewExternal*` 系列（标题/提示/动作/胶囊/toast/折叠行/视图切换）四语言。

## 5. 桌面端改造点（`src/`）

- 文件监视：`FileSystemWatcher` + 500ms 防抖，辅以窗口激活时的 mtime/大小/哈希校验；保存自身写文件时挂起监听。
- diff：行级 + 词级（自研或引入 MIT 协议库，落地时定）；渲染为双栏 `ItemsControl`，词级差异用 Inline 着色。
- 重做 `ShellDocumentReviewView` 的对比区为第 3 节视图；动作沿用现有 `Review*` 命令（保留当前版本 / 另存当前副本 / 载入外部版本），新增胶囊警示态与 toast。
- 键：与第 4 节同名，四语言同步。

## 6. 验收标准

1. 原型：自动保存开 → 触发后正文自动更新且 toast 告知；有未保存键入时不自动载入而进对比；自动保存关 → 胶囊警示 + toast，点开对比；对比视图行级红绿、词级高亮、折叠、双栏滚动同步、并排/统一切换全部可用；四个动作行为正确，载入后可撤销。
2. 桌面端：同上；自身保存不触发；NativeAOT `--verify-runtime` 通过。
3. 对比界面肉眼可直接分辨每处差异（行级定位 + 词级高亮），不再需要逐字比对。
