# Vex 1.5.9 本机验证

验证日期：2026-10-16。系统：Windows x64。版本：1.5.9.0。

## 已通过

- 官方入口 `scripts/publish.ps1 -RuntimeIdentifier win-x64 -Version 1.5.9` 完成 NativeAOT 发布，可执行文件 CLR 目录为零。
- 最终正式可执行文件在独立 Win32 桌面实际启动并绘制主窗口。通过真实菜单打开关于并关闭；打开 MCP 设置后取消关闭，再次打开后保存关闭。配置位于临时复制的发布目录，未执行安装器、未更改默认文件关联。
- 同一正式可执行文件 `--verify-runtime` 检查四语输出资源动态切换及隔离配置往返。
- 真实应用 JIT 离屏验证 640 项：四语切换、宿主同键覆盖、文件工作流、菜单、表格自然列宽、导图、编辑偏好、关于与设置浮层，以及主按钮、危险按钮的八色浅深交互状态。
- 布局专项 JIT 离屏验证 139 项：980/1280/1920 窗口连续拖动，文件与大纲切换、收起恢复、宽度持久化，宽屏正文上限与窄屏边界，以及八色浅深代码、复制操作的字体、对比和高度。拖动期间不保存配置，结束时最多保存一次。
- 共享 Markdown 全部 240 项测试通过，覆盖活动块编辑及半透明代码背景高亮回归。
- 当时维护的五组原型审计及独立 HTML 生成一致性通过（这些原型与流程现已删除）；安装器快照、许可与两语资源契约通过。

## 产物与边界

最终 Windows x64 NativeAOT 可执行文件通过正式运行自检及实际窗口启动验证；文件树、状态栏和编辑快捷栏改动均包含在本次二进制中。

最终 Windows 可执行文件 SHA-256：

```text
eab3fc31a15e0eb1dd6162268477ae9eedaa0d00fd01776b5e4fac600193126d
```

本机一次启动测量从创建进程到可见主窗口为 3404 毫秒，条件为构建后系统缓存已热、独立桌面。它不代表首帧时间、冷启动统计或其他设备性能。

本次界面截图来自上述正式 NativeAOT 程序；文档展示使用隔离副本里的中文示例资源，不改仓库默认新建文案。AOT 编译仍有第三方裁剪及反射告警，其中 Prism 默认 `DialogWindow` 的告警没有命中已验收的 Ursa 关于与设置路径。

JIT 离屏布局检查、AOT 资源自检与 AOT 实际窗口验收分别记录，不互相替代。Linux/macOS 的真实桌面、多 DPI、输入法组合输入和大文档性能未在本次完成全面验收；五平台云端打包结果以 Release 为准。
