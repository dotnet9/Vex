# 开发计划

本文把 `design/` 原型与 `src/` 原生实现逐项对照，列出**已实现基线**、**原型目标但原生缺失的能力**、**原生待补的收尾项**，并给出分阶段落地顺序与验收办法。需求边界见 [需求文档](需求文档.md)，设计准则见 [原型与资源](原型与资源.md)，验证命令见 [开发与验证](开发与验证.md)。

记录基线：Vex 1.8.0，原型 `design/Vex.html`，记录日期 2026-10-22。

## 1. 使用规则

1. **原型是验收基线**：同一尺寸、同一状态、同一语言与主题下比较，差异要么改原生，要么先改原型并说明理由。
2. **一个差距一个编号**：完成后在本表改状态，并在 [更新日志](更新日志.md) 写一条用户可感知的变化。
3. **先规格后实现**：涉及流式、引导、外观令牌的改动，先改对应设计文档，再动代码。
4. **阶段可独立验收**：每个阶段结束时应用能正常构建、运行、导出，不留下半成品入口。

### 5.3 人工验收清单

1. 中文输入法下拖动演示滑块，正文与百分比同步，无跳字。
2. 三种工具条分别取消钉住，2 秒后淡出；重启后状态不变。
3. 引导从开场到末屏连续走完，中途点错门内目标只出现纠正提示。
4. 自定义配色与自定义排版在明暗两态、四语下名称与预览正确。
5. 带水印文档导出 HTML / PDF，字号、颜色、粗细与界面一致。
6. 导图六种布局在长文档（≥ 60 节点）下无重叠、无越界。

## 6. 依赖与风险

| 事项 | 影响 | 处理 |
| --- | --- | --- |
| 导图 6 布局 / 6 样式 | 依赖 `CodeWF.Avalonia.MindView` 12.2 之后版本；应用层无法单独完成 | 先在该库做出布局接口与主题注册，再升级 NuGet；应用先保留一个「布局」下拉占位 |
| 自定义排版 | 共享库 `ArticleTypographyCatalog` 是生成的静态表，尺寸档按 `BodySize` 比例计算 | 需要库内提供注册入口；否则先只做「配色 + 字号档」，排版自定义顺延 |
| 图表渲染完成信号 | 当前渲染是异步且无完成事件 | 优先加事件；退化为轮询 `VisualChildren` 中的 SVG 数量，带 5 秒超时 |
| 水印导出 | `BuildWatermarkCss` 直接拼 SVG，颜色与字号写死 | 改成与界面同一参数源，避免两套默认值 |
| 新增配置键 | `AppSettings` 已有 77 键，磁盘合并逻辑要求缺键可回退 | 新键全部可空并给默认值；不写迁移代码 |
| 原型并进 | 阶段 A7 的 `enableNextForGate` 不修会让门内纠错路径抛错 | 与 A4 同一提交修复，避免引导验收被中断 |
