## V1.11.0（2026-10-25）

- ✨[新增]-发布新增各平台绿色版压缩包：Windows 与 macOS 为 zip、Linux 为 tar.gz，与对应安装包出自同一份产物并附各自的 SHA-256 校验文件，不想安装的用户解压即用；Release 资产因此从五包五校验扩为十包十校验。
- ✨[新增]-安装包维护页按原型重排：已安装行只报本机版本与安装日期，第二行改为事实陈述「安装包 <版本号>」并在右侧标注发布日期、附上「查看更新日志」强调入口——点击后窗口加宽，右栏展开随包的这份更新日志，默认只展开最新一节，更早版本可折叠查看；「打开」彻底移除，右下角唯一一颗执行按钮跟随安装详情里的单选在「升级 / 修复安装 / 卸载」之间切换（卸载降为文字按钮），整页强调色随之落在所选操作上。
- 🐛[修复]-维护页的更新日志栏切坏中文条目——Inno 的 Pos 把非 ASCII 字符按两个单元计数，而取子串按一个字符计，日期括号与标签后的连字符因此落在错位上；改用逐字符定位，发布日期与「[新增] 正文」的切分恢复干净。
- 🐛[修复]-直接打开程序时不再自动载入随包的六份演示文档——未带参数的启动只留一份空白文档，文件列表由用户自己打开决定；演示文档仍可从「文件 → 演示文档」打开，工作区恢复开关的行为不变。
