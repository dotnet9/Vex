# 引导设计（六幕快速上手）

状态：设计定稿，待实施。实施顺序：先原型（`design/`），验收后再桌面端（`src/`）。

## 1. 背景与目标

原型 `design/assets/desktop/guide.js` 现为八幕"自动演示剧"（假光标、打字机、程序驱动），桌面端 `WorkbenchGuideView` 现为六步"用户真实操作"。两边形式与步数均不一致，且原型 VEX_DATA 中的 Guide* 键是更早的五步遗留，已与实际渲染脱节。

本设计将两边统一为**六幕"演示 + 关键入口亲手点"**：写作过程由程序打字机自动完成（用户零输入），凡今后天天要用的入口（换视图、大纲、排版）由用户在聚光灯提示下亲手点击一次。目标：全程约 2 分半，用户点击 15～20 次，教完即会。

已评审淘汰的方案：

- 用户手工输入文字——体验差，取消；打字全部由程序完成。
- 拖拽章节演示——不好演示、易卡住新手，取消。
- 独立的"摘要与节点"一幕——降级为第二幕结尾的一句轻提示。

## 2. 交互模型

| 原语 | 含义 | 卡片行为 |
|---|---|---|
| 【演】 | 程序自动执行：打字机输入、切换视图、点击菜单、定时停顿 | 段末出【继续】；段中用轻提示（气泡）不打断 |
| 【门】 | 等待用户亲手点击指定入口：高亮目标 + 轻提示，不设超时、不判失败 | "继续"永远可点，含义是**程序代点**；用户点到目标即自动进入下一段 |
| 两级门 | 换视图 = "入口按钮 → 二级选项"：先亮入口，弹出后再亮具体项 | 点错项（如点了"三视图"）轻提示纠正"这次选「源码编辑」"，继续等待 |
| 收幕 | 一幕结束的小结卡 | 幕名 + 一句话 +【继续】进入下一幕 |

统一规则：

1. 完成判据走真实状态（布局类名、面板展开、排版键值），但门的"继续"可代点，任何一步都不会卡死。
2. Esc 随时整体退出；"跳过本段"跳到下一幕并铺设该幕基线文档；"上一步"回退一幕。
3. 演示期间屏蔽卡片以外的所有输入（原型与桌面端一致）；退出引导时完整还原文档、视图、排版与滚动位置。
4. 轻提示不可少：每个【演】动作都要有对应的气泡或卡片文案，不允许无说明的自动操作。

## 3. 六幕分镜

示例文档为"成都游记"叙事线，四幕间内容连续演进：

- `stage0` 标题 + 首段；`stage1` 加行程章节（第一天/第二天/锦里夜游）；`stage1WithEnding` 加结尾句；`stage2` 在其上追加 Mermaid 路线图；`routeEdited` 站点更名后。

### 第 1 幕 · 即时与源码（约 35 秒）

1. 【演】清空文档 → 打字机打出标题「# 成都，慢慢走」→ 轻提示：*写下这趟旅行的标题，内容会即时呈现。* →【继续】
2. 【演】打完第一段正文 → 卡片：*内容已经写下，先读一遍刚才的结果。* →【继续】
3. 【门·两级】亮工作台布局按钮：*点这里更换视图* → 画廊弹出后亮「源码编辑」：*选择「源码编辑」* →【演】源码里自动补一句"先喝一碗盖碗茶"→ 轻提示：*刚才的文字都在这里——源码里也能继续修改。* →【继续】
4. 【门·两级】再亮布局按钮：*再切换回「即时编辑」* →【演】补完全文 → 收幕卡：*同一篇游记，两种方式都能继续写。*

### 第 2 幕 · 大纲与导图（约 25 秒）

1. 【门】亮底栏「大纲」开关：*点底栏「大纲」，查看文档大纲* → 展开 → 轻提示：*大纲会列出所有标题。* →【继续】
2. 【演】自动点击大纲项「第一天行程」→ 正文精确定位滚动 → 卡片：*大纲点一下，正文就到位。* →【继续】
3. 【门·两级】亮布局按钮 → 亮「思维导图」→ 切换 → 轻提示：*导图把标题关系画在这里。* → 尾部轻提示：*点击节点可看全文，摘要入口在「工具」菜单。* →【继续】收幕

### 第 3 幕 · 正文排版（约 20 秒）

1. 【门】亮排版按钮：*点「排版」，给文字选一套样式* → 面板弹出
2. 【演】依次应用 简约 → 书卷 → 专栏 → 刊物，每套停 1.2 秒，轻提示同步显示：*排版：书卷*
3. 卡片：*排版会同步应用到阅读和导出。* →【演】自动收面板，收幕

### 第 4 幕 · Mermaid 图表（约 25 秒）

1. 【演】切到源码视图 → 轻提示：*接下来的图表，完全用文字写成。* →【继续】
2. 【演】打字机打出章节标题「## 成都慢游路线」
3. 【演】写入流程图源码块（`flowchart LR`：人民公园 → 宽窄巷子 → 锦里夜游）→ 自动切换「源码 + 预览」→ 下方渲染出路线图 → 卡片：*一段文字，变成了清楚的路线。* →【继续】
4. 【演】自动把源码中「宽窄巷子」改为「宽窄巷子 · 喝茶漫步」→ 路线图同步更新 → 轻提示：*图里的这一站，也跟着更新了。* →【继续】收幕

### 第 5 幕 · 演示模式（约 20 秒）

1. 【演】切到阅读视图并回到顶部 → 卡片：*这篇游记，也可以直接拿来讲。* →【继续】
2. 【演】进入演示模式 → 轻提示：*沿着章节，一段一段展开。* →【继续】
3. 【演】翻到下一页 → 切换导图讲述 → 轻提示：*想先讲全局，也可以从导图开始。* →【继续】
4. 【演】退出演示，回到阅读视图 → 收幕卡：*讲完以后，回到游记继续完善。*

### 第 6 幕 · 保存与分享（约 25 秒）

1. 【演】展开文件菜单，高亮「保存」→ 轻提示：*想继续写，可以保存这份 Markdown。* →【继续】
2. 【演】展开「导出」子菜单，依次亮 HTML / PDF / PNG 长图 / Word → 轻提示：*想交给别人阅读，有现成的格式。* →【继续】
3. 【演】收起文件菜单，展开工具菜单，亮「复制到微信公众号 / 知乎 / 稀土掘金」→ 轻提示：*准备发布时，从这里选择对应的平台。* →【继续】
4. 【演】收起菜单 → 收尾卡：*一篇游记已经成形。* → 末屏「开始自己的写作」按钮，点击退出引导并还原文档。

开场卡：标题「快速上手」，正文 *运行软件即可立即创作哟，跟着演示看一遍核心功能。*，按钮「先不看」「开始吧」。

## 4. 文案键规划（VEX_DATA，四语言）

原型 guide.js 现为硬编码中文，本次迁入 `window.VEX_DATA`，桌面端直接消费同键。约 45 键：

| 键（前缀 `Guide`） | 内容 | 数量 |
|---|---|---|
| `IntroTitle` / `IntroText` / `IntroStart` / `IntroSkip` | 开场卡 | 4 |
| `Title1..6` | 幕名：即时与源码 / 大纲与导图 / 正文排版 / Mermaid 图表 / 演示模式 / 保存与分享 | 6 |
| `Act{n}Summary`（n=1..6） | 各幕收幕卡一句话 | 6 |
| `Act{n}Step{m}` | 各幕分段提示（按上文分镜逐条） | 约 20 |
| `GateLayout` / `GateLayoutSource` / `GateLayoutInstant` / `GateLayoutMap` / `GateOutline` / `GateTypography` | 门引导语 | 6 |
| `GateWrongFormat` | 纠正语：*这次选「{0}」* | 1 |
| `Skip` / `Previous` / `Next` / `Start` / `StepFormat`（`{0} / 6`） | 公共控件 | 5 |

原五步遗留键（`GuideTitle0-4`、`GuideDescription0-4`、`GuideTip0-4`、`GuideVisual*`、`GuideFeedback*`、`GuideStepFormat` 旧值）删除；桌面端同批退役对应的操作检测反馈键。
