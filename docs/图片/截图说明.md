# Vex 文档截图

更新于 2026-11-02，界面版本为 Vex **1.20.0.0**，使用正式 NuGet **CodeWF.Avalonia 12.2.48**。

截图由 `scripts/ui-verification` 的 `docs-shots` 模式驱动应用的真实 Avalonia 控件、ViewModel 和随包 .NET/Avalonia 演示文档，以 Skia 离屏渲染生成，尺寸为 1440×900。主界面为青碧浅色，其余场景使用青碧深色。它们不是浏览器原型，也不是实体 Windows 桌面的截图，不能代替 Native AOT 桌面验收。

覆盖主界面、文件列表与文档大纲、查找替换、八布局切换、源码与阅读对照、单阅读、章节导图、演示、外观、正文排版、偏好设置和导出设置。更新截图应在同一版本下整组重采集，避免混用旧界面。

```powershell
dotnet build scripts/ui-verification -c Release
dotnet run --project scripts/ui-verification -c Release --no-build -- docs-shots <截图输出目录>
```

真实 win-x64 Native AOT 验收、正式依赖还原与验证边界见[验收与已知限制](../验收与已知限制.md)。
