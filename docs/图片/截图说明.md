# Vex 文档截图

更新于 2026-11-08，使用本地验收构建，采集时版本元数据为 Vex **1.21.1.1**，正式 NuGet **CodeWF.Avalonia 12.1.5.2 / Toolkit 1.1.6**。所示菜单和大纲修复纳入 **1.21.1.2**，安装包及发布状态以对应 GitHub Release 为准。

截图由 `scripts/ui-verification` 的 `docs-shots` 模式驱动应用的真实 Avalonia 控件、ViewModel 和随包 .NET/Avalonia 演示文档，以 Skia 离屏渲染生成，尺寸为 1440×900。主界面为青碧浅色，其余场景使用青碧深色。它们不是浏览器原型，也不是实体 Windows 桌面的截图，不能代替 Native AOT 桌面验收。

本次整组重采集 15 张 PNG，覆盖主界面、文件列表与文档大纲、查找替换、八布局切换、源码与阅读对照、单阅读、章节导图、演示、外观、正文排版、偏好设置、导出设置、公式、Mermaid 和大纲阅读跟随。另有 3 段 GIF：四视图切换、大纲导航与阅读跟随、外观切换。每段由 60 张连续真实控件帧生成，按约 100ms 间隔采样，压缩至 1080px 宽；没有用浏览器原型或静态宣传图拼接冒充交互。

```powershell
dotnet build scripts/ui-verification -c Release
dotnet run --project scripts/ui-verification -c Release --no-build -- docs-shots <截图输出目录>
python scripts/encode_docs_gif.py <截图输出目录>/四视图切换 docs/图片/四视图切换.gif
```

真实 win-x64 Native AOT 验收、正式依赖还原与验证边界见[验收与已知限制](../验收与已知限制.md)。
