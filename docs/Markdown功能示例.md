## 练习任务

1. 编辑一句正文，撤销再重做。
2. 用大纲或导图定位本节，观察其他视图。
3. 分别选择两套排版和浅深模式，检查表格没有退回等宽。
4. 保存副本，导出 HTML、PDF、PNG、Word 并打开检查。
5. 关闭未保存副本时分别检查保存、放弃、取消。

更多操作见 [快速开始](快速开始.md)，规格与边界见 [需求说明](Vex需求文档.md)。
