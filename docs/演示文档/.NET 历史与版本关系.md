# .NET 历史与版本关系：语言、SDK、运行时与界面框架

谈论“升级 .NET”时，至少需要区分 **C# 语言版本**、**.NET SDK**、**目标框架 TFM**、**运行时**和 **Avalonia 包版本**。这几个数字相互关联，但不能互相替代。

## 从 .NET Framework 到统一的 .NET

| 阶段 | 代表版本与时间 | 发生了什么 |
| --- | --- | --- |
| .NET Framework | 2002 年开始 | C#、CLR 与基础类库进入 Windows 开发生态 |
| .NET Core | 2016 年的 1.0 | 跨平台、开源和独立部署成为主线 |
| 统一的 .NET | 2020 年的 .NET 5 | 后续主线采用 .NET 名称；没有 .NET Core 4 |
| .NET 6–10 | 2021–2025 年 | 按年度演进语言、运行时、库与部署能力 |

.NET Framework 与现代 .NET 是不同产品线。现有 Windows 系统可以继续维护 Framework 应用；新建跨平台 Avalonia 应用通常选择现代 .NET。

## C# 的演进主线

| C# 版本 | 年份 | 有代表性的语言能力 |
| --- | ---: | --- |
| 1.0 | 2002 | 类型系统、类、接口与委托 |
| 2.0 | 2005 | 泛型、可空值类型与迭代器 |
| 3.0 | 2007 | LINQ、Lambda 与扩展方法 |
| 4.0 | 2010 | dynamic、命名参数与可选参数 |
| 5.0 | 2012 | async 与 await |
| 6.0 | 2015 | 字符串插值、nameof 与空条件访问 |
| 7.x | 2017–2018 | 模式匹配、元组与局部函数 |
| 8.0 | 2019 | 可空引用类型、异步流与范围索引 |
| 9.0 | 2020 | record、init 与顶级语句 |
| 10.0 | 2021 | 全局 using、文件范围 namespace 与 record struct |
| 11.0 | 2022 | 原始字符串、required 与泛型数学所需的接口能力 |
| 12.0 | 2023 | 主构造函数与集合表达式 |
| 13.0 | 2024 | params 集合与 ref struct 相关改进 |
| 14.0 | 2025 | 扩展成员与 field 关键字等 |

这里选取的是学习路线，不是每个版本的完整特性列表。

## 现代目标框架与默认语言版本

| 目标框架 | 对应的默认 C# 主版本 |
| --- | --- |
| `net5.0` | C# 9 |
| `net6.0` | C# 10 |
| `net7.0` | C# 11 |
| `net8.0` | C# 12 |
| `net9.0` | C# 13 |
| `net10.0` | C# 14 |

SDK 决定能使用哪一代编译器，TFM 决定目标 API 与默认语言选择。部分新语法只需要新编译器，部分特性还依赖新的运行时或类库；不能简单认为修改 `LangVersion` 就完成了平台升级。

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
</Project>
```

大多数项目可以采用目标框架的默认语言版本。团队要复现同一套编译环境时，再用 `global.json` 管理 SDK，并保持本地与 CI 的安装一致。

## Avalonia 的版本是另一条轴

Avalonia 是应用引用的 UI 包，不是 C# 编译器或 .NET 运行时。升级时分别核对：

1. Avalonia 包支持的目标框架。
2. 编辑器、主题、图表与其他控件包之间的兼容版本。
3. XAML 编译绑定、反射、序列化与 Native AOT 的实际行为。
4. 源码、即时编辑和阅读模式中的回归测试。

## 发布时应该记录什么

.NET 10 的首次正式发布日期为 **2025 年 11 月 11 日**。本文以 .NET 10 / C# 14 为学习示例，不把预览版本当成正式稳定版本，也不将这个表格当作生命周期承诺。

> 运行一次 `dotnet build` 不能替代发布验证。Native AOT 的最终验收需要对应 RID 的真实产物。
