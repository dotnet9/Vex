代码块左上角显示语言类型，右上角提供下载、换行与复制三个按钮，正文带语法高亮。

```python
# 用递归算斐波那契，演示注释与字符串
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(f"fib(10) = {fib(10)}")
```

```javascript
// 管道式数据处理，演示模板字符串与箭头函数
const words = ["写作", "阅读", "梳理"];
const slogan = words
  .map((word, index) => `${index + 1}. ${word}`)
  .join(" → ");
console.log(slogan);
```

```csharp
// 异步统计非空行数，演示泛型与 await
public static async Task<int> CountAsync(IAsyncEnumerable<string> lines)
{
    var count = 0;
    await foreach (var line in lines)
    {
        if (!string.IsNullOrWhiteSpace(line)) count++;
    }
    return count;
}
```

```cpp
// 快速幂取模，演示指针与模板之外的朴素写法
long long quickPow(long long base, long long exp, long long mod)
{
    long long result = 1;
    while (exp > 0)
    {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}
```

## 颜色与字号

选中文本会弹出浮动工具条（顶部工具条也有字号与颜色按钮），直接调整字号、前景色与背景色（以行内 `<span style>` 落盘）：普通的<span style="color:#c92a2a">红色文字</span>、<span style="background-color:#fff3bf">浅黄底色</span>，也可以组合<span style="color:#1971c2;font-size:18px">蓝色大字</span>与<span style="font-size:12px">小号补充说明</span>。

样式还能叠着用：<span style="background-color:#ecf7ec;color:#30953b">绿底深绿的结论</span>、<span style="color:#d52515">**红色加粗**</span>、<span style="color:#6a3ac7;font-size:20px;background-color:#f3edf9">紫色大字垫浅紫底</span>，嵌在句中依旧随文排版。导出 HTML、PDF 与公众号复制同样保留这些效果。

<span style="font-size: 86px">想</span>法可以很大：选中任意文字，用浮动工具条或顶部工具条把首字放大到 86px，行高自动撑开，其余文字流畅接排。
