# 原型离线依赖与字体

下列资源随 design 目录保存，只供浏览器原型使用，不自动加入 Avalonia 程序或安装包。原型没有 CDN 或其他仓库路径依赖。

| 组件 | 版本 | 用途 | 许可文件 |
| --- | --- | --- | --- |
| KaTeX | 0.16.22 | 数学公式 | [MIT](../../design/assets/vendor/katex/LICENSE) |
| mhchem | 随 KaTeX 0.16.22 | 化学表达式 | [NOTICE](../../design/assets/vendor/katex/mhchem-NOTICE)、[Apache-2.0](../../design/assets/vendor/katex/Apache-2.0.txt) |
| Mermaid | 11.12.0 | 图表 | [MIT](../../design/assets/vendor/mermaid/LICENSE) |
| D3 hierarchy | 3.1.2 | 导图布局 | [ISC](../../design/assets/vendor/d3-hierarchy/LICENSE) |
| Cascadia Code | 随原型保存 Regular / SemiBold | 代码字体 | [OFL](../../design/assets/fonts/CascadiaCode-OFL.txt) |

字体引用使用 design/assets/fonts 的相对路径；KaTeX WOFF2 在其 vendor/fonts 内。界面和中文正文使用系统字体回退，不能承诺不同系统的字形完全一致。插图和品牌 SVG 为项目素材。

应用图标源为仓库根 logo.svg / logo.png / logo.ico；原型默认品牌墨青标识保留在 assets/vex-logo.svg。两者用于各自的实现与设计评审，修改时说明目标，避免在本轮资源整理中隐式替换已发布图标。

依赖来源为 npm 对应版本的发布包：KaTeX、Mermaid、d3-hierarchy；保留许可证与 NOTICE，升级时同时更新本表、资源文件和实际渲染检查。完整入口见 [原型许可](../../design/Third-Party-Licenses.html)。

`design/.gitattributes` 将第三方脚本与字体标记为外部资源，保留原始字节、换行与空白；不要对这些文件运行批量格式化。
