# 配色与正文排版资源

保留原型全部既有方案，补入当前应用的配色与正文排版，形成 **16 套配色、27 套排版**。默认仍为纸白＋品牌墨青与简约正文；原型工作区与交互流程不重设计。应用当前仍为 8 套配色、18 套排版，本轮只整合浏览器资源。

## 共用资源 Key

配色统一使用背景、表面、边框、正文、次要文字、强调色、强调色前景、悬停、按下和选区等 CSS 变量：

| 类别 | 语义 Key |
| --- | --- |
| 布局表面 | --bg、--panel、--surface、--paper、--sidebar |
| 文字与边界 | --fg、--muted、--border、--line |
| 交互 | --accent、--on-accent、--primary、--on-primary、--hover、--pressed、--selection |
| 文档 | --type-size、--type-leading、--typography-accent、--type-on-accent |

不同风格提供这些 Key 的值；控件不按风格名称复制实现。明暗模式、界面配色、正文排版独立选择。排版通过标题结构、装饰、字形、间距和色彩表达区别，不能仅改名称。

## 维护与边界

assets/palettes.js 和 assets/typography-catalog.js 保存原有资源；assets/desktop-resources.js 保存新增资源快照及共用适配。页面均消费合并后的 VexPalettes / VexTypes，不另写一份选择列表。外观对比、偏好、工作区、排版预览和 HTML 副本共用目录。

工作区的正文排版弹层直接展示 27 套效果卡片，统一样例并按实际字号渲染。每张卡片携带独立的排版 Key，与正文及 HTML 副本共用 `VexTypeRules`，选择其他方案不会覆盖卡片自身的样式。紧凑布局同步调整所有卡片的间距，卡片区可竖向滚动。

新增资源快照包含 Studio 的真实浅深色令牌，以及正文主题的强调色和尺寸来源；HTML 的标题装饰是浏览器样式表达，不宣称与 Avalonia 控件逐像素等价。当前应用接入这些合并方案属于后续实现任务。

表格布局是所有风格共用的内容适应规则：按内容分列，不等分、不固定短列占比；超宽表格局部滚动。字号、颜色、边框可随排版变化，列宽规则不随主题退回等宽。

## 原型设计适配

原始资源快照保留在 `design/assets/desktop-resources.js`；界面与正文的语义角色、推荐用途及对比度校正在 `design/assets/design-system.js` 统一定义。小字强调 `--accent`、装饰 `--accent-decoration`、实底按钮 `--primary` 与前景 `--on-primary` 分开；正文使用 `--typography-accent`、`--type-decoration`、`--type-solid`、`--type-on-accent`。

校正后的实际值可与来源色值不同，Key 保持稳定；预览、正文与 HTML 导出共用规则。所有浅色/深色配色与正文排版的组合须满足 [原型设计准则](../../design/原型设计准则.md) 的可读性要求。
