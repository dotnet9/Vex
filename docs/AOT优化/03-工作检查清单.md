## 🔄 回滚计划

### 触发条件
- 关键功能失效
- 性能严重退化（>30%）
- Native AOT 编译失败
- 无法修复的 bug

### 回滚步骤
```bash
# 1. 切换到主分支
git checkout master

# 2. 创建回滚分支（保留记录）
git checkout -b rollback/remove-prism-$(date +%Y%m%d)

# 3. 恢复到合并前状态
git reset --hard HEAD~1

# 4. 强制推送（谨慎）
git push origin master --force-with-lease

# 5. 分析问题
# 查看 feature/remove-prism-for-aot 分支的日志
git log feature/remove-prism-for-aot

# 6. 从备份恢复
cp -r .backup/prism-removal/* src/Vex/
```
