# Vex 需求说明

维刻 Vex · 写下想法，看见脉络。

本规格维护桌面产品范围与验收要求，架构和开发方法分别见 [源码导读](架构与源码导读.md)、[开发与验证](development/开发与验证.md)。已实现与待验证状态见 [验收记录](验收与已知限制.md)。

## 产品定位与平台

面向写作者、开发者和知识工作者，围绕本地 Markdown 的写作、结构整理、阅读和分享提供轻量桌面工作区。文档归用户所有，核心写作不依赖账号或云服务。

只支持 Windows、Linux、macOS。正式交付为 Windows x64 EXE、Linux x64/arm64 DEB、macOS x64/arm64 DMG，各带 SHA256。当前发布配置不承诺其他平台、架构或安装包格式。

## 核心工作流

| 场景 | 要求 | 验收 |
| --- | --- | --- |
| 写作 | 新建、打开、即时编辑、源码、保存与另存为 | 未命名内容可保存；取消与失败不丢内容 |
| 整理 | 打开文件夹、文件列表与大纲、搜索、最近记录 | 切换文件不覆盖未保存内容；路径正确 |
| 结构 | Markdown 章节导图、改名、正文、层级和顺序 | 操作修改同一原文，能撤销、重做 |
| 对照 | 四种视图、八布局及独立视图窗口 | 共用当前文档；布局切换不改正文 |
| 分享 | Markdown、HTML、PDF、PNG、Word 与自媒体复制 | 检查实际文件及目标编辑器的呈现 |
| 演示 | 正文、大纲、导图导航与字号 | 退出恢复原布局、位置和内容 |
| 协作 | 本机 MCP 读取、编辑、保存与基础界面命令 | 鉴权、作用范围、确认和审计有效 |

每个进程维护一份当前文档；文件列表并非多个互不相关的编辑会话。切换当前文件后各视图与独立窗口同步。Markdown 原文是唯一正文来源，不以渲染结果反向替代用户文件。

## 编辑、菜单与导航

保留文件、编辑、段落、格式、视图、工具、帮助七组菜单，支持常用快捷键、右键和键盘访问。编辑动作覆盖标题、列表、引用、任务、代码、表格、链接、图片及行内格式；格式与章节操作进入统一历史。

即时编辑点击正文原位输入；当前应用以 Ctrl+Enter 完成本次块编辑、Esc 恢复块编辑前内容。源码保持完整 Markdown，阅读只读。中文输入法候选、选区、撤销、连续输入和异步剪贴板须分别验证。

查找替换支持大小写、整词、正则、命中计数和循环提示。大纲、导图与正文定位不能制造编辑记录，隐藏视图不做不必要的同步布局。文件改名、删除、外部变更与未保存退出有明确反馈和必要确认。

## Markdown 与表格

支持基础 Markdown、任务列表、表格、脚注、公式、化学表达、Mermaid 和图片等能力；支持范围以实际引擎为准。数学、化学、图表、高亮、上下标、自动链接与软换行可独立设置，不重写原文。

表格列宽按表头与正文内容自适应，短名称列收窄，长解释列得到更多空间，禁止默认等分列宽。通常使用内容宽度，不为了填满区域扩大短列；空间不足时换行或在表格内部横向滚动。至少用“负责方 / 职责 / 示例”三列样本检查长短内容，覆盖单视图、三视图和深浅模式。

代码、宽表格、长链接、复杂公式与图表不遮挡正文或按钮。图片按来源和相对路径处理，同名不同内容保留新文件；资源复制不得越过允许目录或覆盖原附件。

## 文件与数据

识别 .md、.markdown、.mdown、.txt。打开文件保留实际路径、编码和换行；新文档使用配置默认值。保存状态反映实际结果，取消选择目的地不显示成功。

已有文件自动保存默认关闭，仅在启用且磁盘内容未被外部修改时执行；具名文档与未命名草稿分开处理。恢复草稿用于故障恢复，不能取代正式保存与独立备份。手动保存、自动保存、外部变更和恢复的实际实现边界见 [架构说明](架构与源码导读.md)。

删除显示目标并确认；切换、关闭、更新安装前检查未保存内容。扫描大目录和长文档不能长时间阻塞 UI，应保留可取消、可返回或渐进显示的改进目标；不把旧文档中固定的扫描数量当作源码已经实现的限制。

## 外观、排版与本地化

明暗模式包括浅色、深色、跟随系统。界面配色与正文排版分别选择和持久化，切换不能重置正文、历史或位置。语义资源 Key 一致，不同风格通过资源值表达，标题、引用、代码和表格要有辨识度及清晰对比。

当前应用为 8 套界面配色和 18 套正文排版；原型整合为 16 套和 27 套，保留原默认外观，新增资源尚需另行接入应用。名称与 Key 见 [外观资源](resources/外观资源.md)。四种界面语言为简体中文、繁体中文、英文和日文，所有窗口与长文本须适应翻译长度。

## 导出与分享

导出覆盖 Markdown、HTML、PDF、PNG 和 Word。PDF 正文应可选择复制；PDF、Word 的图片嵌入和离线可读性需实际检查。纸张、边距、水印、HTML 样式和目录等偏好按格式生效，预览水印与导出水印独立控制。

自媒体复制复用当前文档与实际导出能力，在微信公众号、知乎、稀土掘金的目标编辑器检查结果。不能因为原型可复制或目标平台曾经支持某种格式，就承诺所有网站版本完全保留样式。分享不等于自动发布。

## 非功能要求与验收

- 默认工作区克制、可直接写作；状态有文字提示，焦点明确、键盘可达。
- 最小桌面窗口、长文件名、四语言、深浅色、多 DPI 与跨屏不发生按钮遮挡或正文挤压。
- 长文的统计、大纲、查找与预览采用适当防抖或延迟派生；性能结论记录机器、输入、构建方式和运行时。
- 数据失败优先保留用户内容；不把恢复草稿、排他自动保存或浏览器演示描述为绝对事务和永久备份。
- 使用可追溯依赖并保留许可；MCP 不能越过配置范围随意读写磁盘。
- 按 [验收清单](验收与已知限制.md) 区分源码测试、离屏界面、真实桌面、原生安装与跨平台验收；不凭测试数量声明视觉一致率。
