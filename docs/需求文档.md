# Vex 需求文档

## 1. 产品定位与范围

维刻 Vex 面向写作者、开发者和知识工作者，提供围绕本地 Markdown 的写作、结构整理、阅读、演示和分享工作区。正式文档与附件由用户选择保存位置，核心写作不依赖账号或云服务。

本规格基于 1.7.0。当前实现和验收程度分别见 [概要设计](概要设计.md)、[详细设计](详细设计.md) 与 [验收记录](验收与已知限制.md)。下文的验收条件是应达到的标准，不表示每项都已在所有系统实机完成。

| 范围 | 要求 |
| --- | --- |
| 平台 | Windows、Linux、macOS 桌面 |
| 正式分发 | Windows x64 EXE；Linux x64 / arm64 DEB；macOS x64 / arm64 DMG；每包配套 SHA256 |
| 文档模型 | 每个进程一份当前 Markdown，文件列表负责切换；多个视图和独立窗口共享它 |
| 数据归属 | 用户本地文件、附件和配置；草稿只是故障恢复辅助 |
| 范围之外 | 云端同步、多人实时协作、独立多文档标签、移动端、自动发布文章、任意电脑远程控制 |

不为旧原型增加兼容层。项目文件中的其他 RID、旧打包脚本及浏览器模拟流程不扩大正式交付范围。

## 2. 用户场景

| 场景 | 主要流程 | 完成标准 |
| --- | --- | --- |
| 写一篇文章 | 新建 → 即时编辑 / 源码 → 保存 | 内容与所选路径一致，取消和失败仍保留内容 |
| 整理知识目录 | 打开文件夹 → 筛选 → 打开 → 折叠文件 / 大纲 | 重启恢复主动选择的折叠状态，切换不丢未保存内容 |
| 调整文章结构 | 导图 / 章节详情 → 改名、改正文、移动层级和顺序 | 同一 Markdown 同步变化，修改能撤销和重做 |
| 阅读与讲解 | 切换阅读 / 对照布局 → 演示 → 返回 | 位置和布局恢复，演示导航不写入正文历史 |
| 对外分享 | 选排版 → 导出 / 复制到目标平台 | 实际文件可读，导出失败可重试，导出不代替正文保存 |
| AI 辅助 | 启用本机 MCP → 只读验证 → 确认修改 | 鉴权、目录范围、确认、撤销和审计有效 |

## 3. 功能需求

| 编号 | 需求 | 关键验收条件 |
| --- | --- | --- |
| FR-01 | 新建、打开、保存、另存、改名、删除及最近记录 | 支持 `.md`、`.markdown`、`.mdown`、`.txt`；保留实际路径与编码；取消不显示成功；删除明确目标并确认 |
| FR-02 | 打开文件夹、文件筛选、排序与树 / 列表导航 | 切换文件先处理未保存内容；文件监视发现变化后提供选择，不能静默覆盖当前编辑 |
| FR-03 | 即时编辑、源码编辑及统一历史 | 即时编辑 `Ctrl+Enter` 完成、`Esc` 取消本块；源码 / 即时输入器互斥；格式、章节及 MCP 正文修改可撤销 |
| FR-04 | 格式工具、查找替换与剪贴板 | 常用标题、列表、任务、引用、代码、表格、链接、图片和行内格式；查找支持大小写、整词、正则、计数及循环提示；HTML 粘贴转 Markdown |
| FR-05 | 四种视图、八种布局及独立视图窗口 | 即时、源码、阅读、章节导图共享原文；布局、缩放和定位不改变正文；独立窗口随当前文件同步 |
| FR-06 | 大纲、文章信息及章节详情 | 共用辅助栏；定位与编辑语义分开；章节拖动携带子章；CRLF、同名标题、标题前插入内容不破坏结构识别 |
| FR-07 | Markdown 渲染与图片 | 支持任务、表格、脚注、公式、化学表达、Mermaid 等引擎能力；七项语法可设置；附件使用相对路径时保留目录关系，同名不同内容不覆盖 |
| FR-08 | 自动保存、恢复草稿与外部冲突保护 | 自动保存默认关闭，只写已有文件且磁盘仍为保存基线；草稿可全文预览，恢复为独立未保存文档；失败持续提示并支持重试 |
| FR-09 | 用户操作状态持久化 | 文件夹折叠、大纲折叠、导航模式、排序、辅助页签、宽度、布局、外观和编辑偏好写入配置；搜索临时展开不覆盖用户折叠选择 |
| FR-10 | 主题、配色、正文排版与四语 | 浅色 / 深色 / 跟随系统，16 套配色、27 套正文排版；中文简体、中文繁体、英语、日语；切换不重置正文、历史和选中文件 |
| FR-11 | 演示、新手引导、专注及打字机模式 | 演示正文 / 大纲 / 导图可导航；退出恢复全文锚点；引导完成或跳过后恢复原文、历史、布局和原独立窗口 |
| FR-12 | 导出及自媒体复制 | Markdown、HTML、PDF、PNG、Word；微信公众号、知乎、稀土掘金富 HTML 复制；实际检查图片、字体、分页和目标平台效果；不自动对外发布 |
| FR-13 | 检查更新及原生安装 | 匹配平台资产、校验 SHA256；Windows 确认安装器窗口就绪后才退出；注册打开候选尊重安装选项及系统默认应用设置 |
| FR-14 | 本机 MCP | 默认关闭，回环监听，Bearer Token，29 个白名单工具；路径范围、必要确认、UI 线程执行及审计；详细参数见 [接口文档](MCP功能实现方案.md) |

### Markdown 和表格专项

表格列宽依据表头和正文内容分配，短名称列收窄，长解释列获得空间；不能默认等分，也不应为填满区域拉宽短列。空间不足时换行或在表格内部横向滚动。使用“负责方 / 职责 / 示例”等长短内容混合样本，检查单视图、三视图及深浅模式。

代码、长链接、宽表格、复杂公式和图表不能覆盖其他正文或按钮。PDF 正文可选取，图片嵌入及离线读取需要逐格式检查；不能从浏览器预览推导所有导出格式等价。

### 数据失败处理专项

保存、导出、草稿分别展示失败和重试入口。继续输入不能清除尚未解决的失败标记；取消重试不能显示成功。恢复、切换、退出及更新交接均须经过未保存保护。恢复草稿不能取代用户备份，手动保存的当前实现也不提供完整文件事务保证。

## 4. 非功能需求

| 编号 | 目标 | 验收方法 |
| --- | --- | --- |
| NFR-01 | 与 `design` 原型在布局、资源、交互、动效和安装流程上高度一致，目标 ≥98% | 同尺寸、同状态、同语言和主题截图比较；说明字体容差与统计范围；应用和各系统安装器分别记录 |
| NFR-02 | 连续输入与布局切换保持可用，长文派生工作避免占满 UI | 记录文档规模、机器、运行时、构建类型及负载；分开计量冷启动、首次 JIT、连续输入、视图切换和渲染 |
| NFR-03 | 动效可关闭且不引起正文逐帧重排 | 检查中间帧、最终状态、快速显隐、移出视觉树及开关切换后的任务和订阅释放 |
| NFR-04 | 多语言、键盘、最小窗口、多 DPI 与跨屏可用 | 检查焦点恢复、Esc、长翻译、滚动和按钮可达性；真实中文输入法另行实机验证 |
| NFR-05 | 本地数据和权限可解释 | 故障保留内容；MCP 默认关闭且不越界；Token 与备份脱敏；卸载不主动删除用户 Markdown |
| NFR-06 | 可维护、可原生发布 | 中央包版本、可追溯许可、静态 AOT 元数据；共享库通过 NuGet 消费；五个平台在对应原生 runner 构建 |

98% 是明确目标，不作为未经测量的宣传结论。当前数值只覆盖 Windows 安装器指定十张截图，完整应用和跨平台实机边界见验收文档。
