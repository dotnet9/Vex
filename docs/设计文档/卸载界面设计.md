# 卸载界面设计

实施顺序：先原型（`Vex-Installer-Windows.html` 卸载页签），验收后 `scripts/installer/CodeWF.Setup.Uninstall.iss`。中英双语落地。

## 1. 页面结构

| 屏 | 出现时机 | 内容 |
|---|---|---|
| 确认页 | 用户从系统发起卸载 | 挽留文案 + 保留数据选项 + 反馈入口 |
| 进行页 | 用户确认后 | 现有卸载进度页，不变 |
| 完成页 | 卸载成功 | 感谢 + 反馈引导 |

## 2. 确认页

- 标题：*确定要卸载维刻 Vex 吗？*
- 挽留文案：*有点舍不得。Vex 是免费的开源软件，还在持续成长——如果遇到了问题，告诉我们，也许马上就能解决。*
- 勾选项（默认勾选）：*保留我的文档与设置*，说明行：*配置位于 %APPDATA%\Vex，文档不受卸载影响。*
- 链接：*卸载前反馈问题 »* —— 打开 GitHub Issues 并预填卸载反馈模板（版本号、原因单选：遇到 Bug / 缺少功能 / 性能不满意 / 其他）。
- 按钮：`保留 Vex`（主按钮，取消卸载）｜`继续卸载`。

## 3. 完成页

- 标题：*已卸载维刻 Vex*
- 感谢文案：*感谢你使用维刻 Vex——你的每一次反馈，都会让下一版更好。*
- 按钮：`反馈卸载原因`（GitHub Issues 预填模板，同确认页链接）｜`访问官网`（https://vex.codewf.com ）｜`完成`
- 说明行：*你的文档未被删除；配置已按你的选择保留 / 清除。*

## 4. 反馈链接

`https://github.com/dotnet9/Vex/issues/new?template=uninstall-feedback.md`，模板随仓库 `.github/ISSUE_TEMPLATE/uninstall-feedback.md` 落地（实现阶段新增）：正文预填版本号（读注册表 DisplayVersion）、原因单选项、可编辑的补充说明。

## 5. 原型落地（`Vex-Installer-Windows.html`）

- 新增「卸载」演示页签，含确认 / 进行 / 完成三屏，可切换预览；沿用现有安装原型的明暗主题与框架视觉。
- 文案键进入 `Vex-Installer-Windows.html` 的双语字典（与安装页同机制）。

## 6. `.iss` 落地（`CodeWF.Setup.Uninstall.iss`）

- 确认页替换原生 `MsgBox`：自绘挽留页（复用现有 GDI 框架绘制），`保留 Vex` 走 `CancelButtonClick` 退出路径。
- 完成页：卸载成功后的收尾态在自绘窗口内呈现；两个反馈按钮 `ShellExec` 打开预填链接。
- 中英文案进 `[CustomMessages]`（`CWU*` 前缀沿用）。

## 7. 验收标准

1. 原型三屏可切换预览，中英切换无缺文案；挽留、感谢、反馈入口齐备。
2. 实装：确认页勾选「保留文档与设置」卸载后配置仍在；取消勾选则配置目录一并清除；两个反馈链接打开预填 Issue；`保留 Vex` 取消卸载且不留残留状态。
