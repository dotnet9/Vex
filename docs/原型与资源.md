本文是 `design` 的统一设计准则、资源目录和维护说明。需求见 [需求文档](需求文档.md)，桌面实现见 [详细设计](详细设计.md)，命令见 [开发与验证](开发与验证.md)，目录分层见 [design/README.md](../design/README.md)。原型用于确认设计，应用、导出与系统安装各自验收。

## 1. 预览与页面

在仓库根运行 `node design/scripts/preview.cjs`，访问 http://127.0.0.1:4317/design/ 。仅需 Node，监听 127.0.0.1，默认端口 4317，可用 VEX_PREVIEW_PORT 修改。服务提供原型资源及集中 Markdown 文档，不提供任意仓库文件。

也可先运行 `node design/scripts/sync.cjs` 再直接打开 [index.html](../design/index.html)。离线复制时保留完整 design；若要查看集中说明同时带上 docs。版本来自 Directory.Build.props，内置鸣谢和更新日志来自本仓 docs/鸣谢.md 与 docs/更新日志.md；生成 `project-info.js` 和 `generated/documents-data.js`。直接打开后若源文档有变，需要重新同步。

## 2. 设计准则

### 内容层级与几何

文章是第一层，当前文档 / 布局 / 保存是第二层，导航和辅助说明为第三层。保留七组菜单、八布局、左右导航和右辅助栏；窄窗继续桌面交互。编辑工具靠近编辑区，排版靠近正文，大纲 / 信息 / 章节详情共用右栏。

常用间距 4 / 8 / 12 / 16 / 24 / 32px，组件圆角 4 / 6 / 8px，主要浮层可 10px。阴影表达浮层层级。工具和辅助字 12～14px，正文 16～18px 起，常规行高 1.8～2.0，紧凑约 1.65；紧凑先收间距，正文不小于 16px。阅读限制行宽，代码、表格和图表保留自身横滚。

标题栏外观、语言和窗口按钮中心线对齐，三平台保留各自窗口习惯。原型窗口外舞台固定 `#EAECEA`，只让软件内部随主题变化；品牌标识保持 `#24766B`。原生尺寸见详细设计，安装器尺寸见安装发布指南。

### 语义颜色与可读性

| Key | 职责 |
| --- | --- |
| `--bg`、`--paper`、`--panel`、`--surface`、`--sidebar` | 工作区、正文纸面与表面层次 |
| `--fg`、`--muted` | 正文与辅助文字，在实际合成背景检查 |
| `--accent`、`--accent-decoration` | 小字强调与非信息性装饰分别取值 |
| `--primary`、`--on-primary`、hover / pressed | 实底按钮与专用前景独立成对 |
| `--accent-soft`、`--hover`、`--pressed`、`--selection` | 选中、悬停、按下与选区 |
| `--border`、`--control-border`、`--focus-ring` | 轻分隔、必要控件边界与键盘焦点 |
| `--fg-disabled`、`--status-error` 等 | 禁用和语义状态，配合文字而非只换颜色 |
| `--typography-accent`、`--type-decoration`、`--type-solid`、`--type-on-accent` | 正文标题、装饰和实底元素 |

所有方案使用共同 Key，风格通过值表达；不复制控件实现或让一种高饱和色同时承担文字、装饰和按钮底色。浅深分别设计。文字至少 4.5:1，大字至少 3:1；本项目正文标题矩阵按 4.5:1 验证。焦点和状态按 3:1 检查；`--control-border` 是规则 §3 的固定派生（ink@20% / ink@26% 烘焙到 paper），校验的是「与规则公式一致」，不套用面向文字或图形的阈值。装饰线不等同必要边界。比较合成后的实际背景，色板原值不是完整验收。

每类控件定义默认、hover、pressed、selected、focus、disabled，输入另有 readonly、error；不叠加透明度让文字不可读。选项用勾选 / 文字 / 语义表达，危险动作明确后果，错误说明内容是否保留及可执行重试。

### 菜单、选择与焦点

一级与级联菜单、外观和语言面板统一 248px；布局和排版属于内容面板，不套此宽度。长项换行、末项内部可滚动，靠边级联翻转 / 限位。支持方向键、Home / End、Enter、逐级 Esc，关闭回触发控件。模态约束焦点，取消返回原文档位置。

配色推荐 4 套、排版推荐 6 套，全部 9 / 12 一键可达，当前方案始终可见且有用途提示。12 张排版卡各自以真实 13 / 15 / 17 字号档渲染相同标题、正文和引用；方向键只移焦点，点击或确认才应用，应用后保留弹层和滚动位置。固定头部与筛选，卡片区独立滚动，小窗减少列数而不压坏卡片。

右键与 Shift+F10 按选区或元素提供操作；只读区禁改。异步粘贴 / 图片选择 / 确认回来后重新检查文档与选区；IME 组词期间不抢候选快捷键。章节操作可撤销，主题 / 排版 / 布局不改原文或清历史。保存、恢复、外部版本和关闭遵循 [数据保护设计](详细设计.md#5-文件工作流与内容保护)。

### 表格、图表与动效

表格按内容分列，不等分、不把短列固定比例拉宽，宽表局部滚动；不设计 Markdown 无法表达的合并单元格。至少以短“负责方”与长“职责 / 示例”对比。图表按正文宽度等比缩放，完整显示，不出现内部滚动条；导图类型提示与标题同行且减弱。图表范围见 [Markdown 示例](Markdown功能示例.md)。

图表使用视口附近优先的渲染队列；隐藏视图和离屏图表暂不出图，切换文档清理旧任务。阅读与即时编辑共享最多 48 项 SVG 布局缓存，每次挂载重新分配内部 ID，避免箭头和样式串图。每张图表之间让出事件循环，保持导航和输入响应。

排版预览、文章和 HTML 副本共用规则；导出为独立浅色纸面，离开软件主题后仍可读。动效使用 140 / 220 / 260ms 和透明度、6px 位移，避免逐帧布局；开关关闭、隐藏和销毁均取消并清订阅。引导使用临时文章，完成 / 跳过恢复原文、历史、布局、偏好和窗口。

## 3. 配色与正文排版目录

界面配色已切换为 9 套高对比配色（3×3 九宫格目录），默认靛蓝 Indigo：graphite 石墨、indigo 靛蓝、teal 青碧、pine 松绿、sky 天青、amber 琥珀、crimson 绯红、violet 紫晶、terracotta 陶土。唯一事实源是 [CodeWF.Avalonia《配色与排版令牌规则.md》](../../libs/CodeWF.Avalonia/docs/配色与排版令牌规则.md) 附录 A：每套只编写 4 色（纸面 / 面板 / 墨色 / 强调；状态色取全局默认），其余语义键按规则 §3 派生并烘焙为不透明色，由 [palette-rules.cjs](../design/scripts/palette-rules.cjs) 生成 [palettes.css](../design/assets/prototype/palettes.css) 与 [palettes.js](../design/assets/prototype/palettes.js)，对比度校验（§5）不通过则拒绝落盘。产出带版本戳、禁止手写（§14）；[palette-rules.js](../design/assets/prototype/palette-rules.js) 是生成器与浏览器自定义配色编辑共用的派生模块（Appearance.html「自定义配色」按 §7 的 4 色编写实时派生）。旧 16 套不保留，旧 Key 由 palettes.js 内置别名映射（weft→teal、ocean/dotnet/night-sky→indigo、sand→amber、rose→crimson、iris→violet、olive→pine、ember→terracotta 等）。

界面密度三档（紧凑 / 正常 / 宽松）由同一生成器产出 [density.css](../design/assets/prototype/density.css)（规则 §6 显式值表），外观菜单与 Appearance 评审页均可切换；正文排版的尺寸档与界面密度独立（§11）。

## 4. 资源源头与同步

[palettes.js](../design/assets/prototype/palettes.js) 与 [palettes.css](../design/assets/prototype/palettes.css) 由 palette-rules 生成器产出（勿手写，改动附录 A 后重跑 `node design/scripts/palette-rules.cjs`）；[typography-catalog.js](../design/assets/prototype/typography-catalog.js) 保留排版目录；[desktop-resources.js](../design/assets/prototype/desktop-resources.js) 仅保存排版来源快照，配色注入已移除。[design-system.js](../design/assets/prototype/design-system.js) 负责正文排版的对比度校正与目录精选，页面消费统一 VexPalettes / VexTypes / VexTypeRules。

[sync_native_design.cjs](../scripts/sync_native_design.cjs) 从原型生成独立库的原生目录、浅深令牌、标题参数和浅色 HTML 样式。它会写库仓，修改前查看脚本目标；生成后按本地 NuGet 流程验证和发布，不能绕过包消费。根 logo.svg / PNG / ICO 已统一原型绿色，Windows、Linux、macOS 图标均取同一源；不要从浏览器 vendor 把依赖误复制到桌面包。

## 6. 设计验收清单

| 范围 | 检查 |
| --- | --- |
| 颜色与排版 | 9 × 2 × 12 的正文、标题、链接、引用；实底按钮三态、边界和焦点 |
| 选择面板 | 推荐 / 全部、当前标记、独立效果卡、键盘不误应用、紧凑和滚动末项 |
| 尺寸与语言 | 800×480、1024×768、1440×1000，三平台标题栏、四语、长菜单与文件名 |
| 内容安全 | 切换后原文 / 历史 / 位置，章节撤销，失败重试，外部比较与草稿恢复，未保存取消 |
| 阅读细节 | 自适应表格、甘特 / C4 / XY 标签、导图弱提示和窄栏横滚 |
| 完整任务 | 打开 Markdown → 编辑 → 调整章节 → 保存副本 → 导出 HTML，检查实际内容 |
| 静态与离线 | 脚本无错、资源和文档链接存在、生成帮助同步、许可可读 |

静态及三类浏览器命令见开发指南。浏览器矩阵、原生资源矩阵、Windows 安装器图像指标各自记录，不相互替代；结果与实机缺口统一在 [验收与已知限制](验收与已知限制.md)。
