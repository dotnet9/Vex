## 文档维护约定

- 当前实现以 `src/`、构建配置、安装脚本和实际发行产物为准；原型用于确认视觉与交互目标，不作为已经实现的证明。
- 需求、架构、开发方法和资源说明集中在本目录；根目录保留项目首页与供发布工具读取的更新日志，脚本目录的 README 保留就近导航或命令契约。
- 历史验证记录保留原日期、版本与证据边界，不把过去的检查写成本轮重新执行。旧源码路径和仓外证据仅用于追溯。
- 原型内的版本、鸣谢和更新日志由 `node design/scripts/sync.cjs` 从当前仓库生成。第三方 LICENSE、NOTICE 和字体许可继续随资源保存。

本次整理只涉及原型、资源与文档，应用功能及正式发布矩阵没有据此变更。新的视觉要求应先验收原型，再安排应用适配。
