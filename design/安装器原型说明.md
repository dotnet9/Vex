# Vex 安装器交互原型

安装原型按平台拆成三个独立 HTML，英文名 **Vex**，中文名 **维刻**，Slogan **维刻 Vex · 写下想法，看见脉络。**，内嵌版本快照为 **1.6.3**：

| 平台 | 独立文件 | 安装流程 |
| --- | --- | --- |
| Windows | [Vex-Installer-Windows.html](Vex-Installer-Windows.html) | 单角切口、单页一键安装、维护与卸载 |
| Linux | [Vex-Installer-Linux.html](Vex-Installer-Linux.html) | DEB 软件包详情、系统授权、安装与移除 |
| macOS | [Vex-Installer-macOS.html](Vex-Installer-macOS.html) | DMG 拖放复制、替换与推出 |

直接双击对应文件即可打开。原混合文件 `CodeWF.安装器原型.html` 已拆分移除。

## 单仓独立维护

每个 HTML 内嵌自身全部 CSS、脚本与 SVG，可以单独复制到空目录离线打开，不依赖另外两个平台、邻仓文件或主应用原型。

三个文件分别维护，没有运行时共享或自动覆盖机制。更新版本时修改各文件内 `products` 的 Vex 版本与文案。平台由文件固定，不提供平台切换或其他产品选择。HTML 不是生产安装器的构建输入，不会自动改变安装脚本或发布版本。

产品使用 **维刻 / Vex**，出品品牌为 **CodeWF**。Windows 页脚品牌可点击打开 <https://codewf.com>。品牌紫 `#512BD4` 作为主按钮和产品图标配色。保存文件使用 UTF-8，保持每个平台单文件交付。

## 视觉与交互

页面只显示对应平台的安装窗口及其交互弹窗。已移除窗口外的页头、工具栏、平台与产品选择、架构选择、步骤预览、情景下拉框、特效预览、重置和说明页脚。macOS 只保留 DMG 安装，不包含 PKG 提案或 Windows 向导。

Windows 使用约 **520 × 366** 的极简窗口，右下角保留 **26px 单角切口**，其余边缘圆角。首页只显示产品图标、Vex、新 Slogan、“立即安装”和“自定义安装”，页脚显示出品品牌、版本与开源许可。移除六步向导、部署舱、轨道环、粒子、技术栈标签和安装前确认页。展开设置或显示操作状态时窗口按内容增高。

默认使用简体中文并跟随系统浅深主题；英文采用对应的品牌译文。系统“减少动态效果”会停止进度过渡动画，保留可读状态与进度。安装进度仅用于模拟反馈，不额外等待动画播放。

- Windows：点击“立即安装”直接开始，固定按当前用户安装；“自定义安装”折叠保留目录、路径校验、浏览、桌面快捷方式和 Markdown 打开方式。MIT 许可可随时查看，无独立许可确认步骤。安装完成可“打开 Vex”或“关闭”；维护提供修复和卸载，保留失败重试与取消确认。
- macOS DMG：Finder 模型，支持拖放应用到 Applications，也可聚焦应用图标后按 Enter 或点击 Applications；支持复制、替换、失败重试、取消和推出。
- Linux DEB：精简为产品信息、安装按钮与可展开的软件包信息，保留系统认证、安装、打开与移除。位置与范围由包管理器管理。

Windows 标题栏只保留关闭；Linux/macOS 最小化后可再次点击标题栏的最小化按钮还原。关闭、完成退出或推出后窗口隐藏，刷新页面重新打开。

## 无界面的评审参数

为保持页面只包含安装窗口，评审入口放在 URL 参数中，各文件均可使用：

- `?scenario=installed`：Windows 显示维护入口，Linux 显示已安装状态，macOS 复制时提示替换。
- `?scenario=error`：首次操作中途失败，重试后完成。
- `?lang=en`：英文；`?theme=light` 或 `?theme=dark`：固定主题。
- 参数可以组合，例如 `Vex-Installer-Windows.html?scenario=installed&lang=en&theme=dark`。

## 本仓验收

在 `design/tests` 安装依赖后运行 `npm run test:installers`。可通过 `VEX_BROWSER_EXECUTABLE` 指定本机 Chromium 或 Edge 路径。

审计将每个 HTML 单独复制到空目录，验证没有外部文件或网络依赖、没有平台混合或评审外壳，并检查品牌文案、1440/800/390/320 像素宽度下的浅深主题、一键安装、折叠设置、许可查看、取消与暂停、失败重试、Windows 维护与卸载、Linux 授权与移除、macOS 拖放与替换。截图输出到系统临时目录。手工可补充检查 Tab、Enter、Escape，以及系统减少动态效果设置。

进度、空间、账户、目录及错误场景为模拟数据。密码输入为只读示例，不收集密码。除用户主动点击官网链接外，页面不发网络请求，不访问磁盘、注册表或安装服务，不写本地存储。原型不证明真实系统安装、提权、签名、公证、卸载或多 DPI 已验收；macOS Finder 与 Linux 软件管理器的真实外观由操作系统控制。
