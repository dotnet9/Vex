# Vex 工作台原型

本目录是单页、可交互的产品原型。设计以写作、阅读和结构梳理为中心。原生应用已同步三视图工作台、即时渲染、Markdown 导图、菜单与新手引导，回归入口见 `scripts/ui-verification/README.md`。

## 打开方式

直接打开 `design/index.html`，默认进入编辑视图。也可以在仓库根目录启动本地服务：

```powershell
python -m http.server 8791 --bind 127.0.0.1
# 编辑：http://127.0.0.1:8791/design/index.html
# 导图：http://127.0.0.1:8791/design/index.html?view=mindmap&palette=aurora&theme=light
```

支持 URL 参数 `view=edit|read|mindmap`、`edit=instant|source`、`typography=Simple|TechnologyBlue|…`、`palette` 和 `theme=light|dark|system`。

## 工作台设计

- **编辑**：默认“即时渲染”，点击正文编辑当前块，输入时同步显示排版效果，离开后恢复正文排版；也可切换“源码对照”，并按需关闭右侧预览。编辑方式记住上次选择，三个主视图使用同一份内容。
- **阅读**：只读正文独占内容区；保留文档导航，适合长文阅读。
- **导图**：默认使用完整画布；按需打开“对照源码”，点击节点显示全文，再定位并选中原始源码。
- 侧栏集中放文档列表、搜索和标题大纲；文档切换同步正文、导图、文件名与统计。未保存修改可取消切换、保存副本或放弃。
- 状态栏只保留修改状态、当前视图、光标位置、字符数、编码和主题。统计与文档属性使用当前内容计算。

菜单按任务分组：

| 菜单 | 内容 |
| --- | --- |
| 文件 | 新建文档 / 窗口、打开文档 / 文件夹、快速打开、最近文档、编码重开、保存 / 另存为 / 保存全部、导出、打印、属性、位置、删除、关闭 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、复制纯文本、全选、查找、替换 |
| 插入 | 段落、H1–H6、三种列表、引用、表格、代码块、公式块、分割线、链接、图片、加粗、斜体、行内代码、清除格式 |
| 视图 | 三个主视图、编辑方式、文档导航、编辑显示、写作辅助、Markdown 排版、界面配色、语言、窗口 |
| 工具 | 导图显示设置、统计、刷新、平台复制、MCP 设置与审计 |
| 帮助 | 新手引导、更新日志、鸣谢、网站、反馈、关于 |

对照依据为 `src/Vex/Modules/Shell/Views/ShellTitleMenuView.axaml`。原“段落 / 格式”合并为“插入”；排版、配色和语言从“帮助”移到“视图”；平台复制、统计、刷新和 MCP 集中到“工具”。保留原生已有功能入口，桌面功能标注为操作演示。

菜单统一使用文字，无装饰图标；仅保留选中勾号和子菜单箭头。快捷键使用右对齐的次要文字，不加背景或边框。`Ctrl+P` 为快速打开，`Ctrl+Shift+P` 为打印预览，与现有实现一致。支持上下键选择、右键进入子菜单、左键返回和 Esc 关闭。

## 编辑与 Markdown 排版

- 即时渲染属于编辑方式，不增加第四个主视图，避免把输入方式和阅读 / 结构视角混在同一层。
- 原型采用分块编辑：当前块保留 Markdown 输入区和实时效果，其他块保持排版。输入期间保留光标和编辑 DOM；`Ctrl+Enter` 完成，`Esc` 取消当前块，支持菜单撤销 / 重做。正式版的连续富文本编辑、光标映射与中文输入法需另外验证。
- Markdown 排版提供现有实现的 18 个名称与主题键，默认“简”，另有紧凑布局。可从“视图 → Markdown 排版”或正文右上角打开，偏好本地保存；即时编辑、源码预览与阅读同步应用，HTML 导出携带对应样式。
- Markdown 排版控制正文；界面配色控制工作台。两者独立设置，排版强调色随浅深模式调整。主题 CSS 是原型效果，不代表已经精确复刻原生主题。
- 自动配对输入、专注模式、打字机模式、界面动效开关可操作。`F8` 切换专注，`F11` 演示全屏；动效同时尊重系统减少动态效果设置。

## 新手引导

首次使用在工具栏显示“快速上手”，由用户选择开始；完成或跳过后隐藏这个入口，仍可从“帮助 → 新手引导”重复体验。直接预览：`design/index.html?tour=1&palette=aurora&theme=light`。

引导为 5 个可操作的重点：

1. **三个视角**：实际切换编辑、阅读、导图，认识文档导航和工作区。
2. **即时写作**：点击演练段落输入文字，查看当前块实时排版，同时解释源码对照的使用场景。
3. **正文排版**：点击主题卡片，聚光同时显示色板和正文标题，区分正文主题与界面配色。
4. **导图结构**：调整默认 30 字摘要、点击节点查看全文、定位源码，介绍折叠、平移和缩放。
5. **日常入口**：自动展开文件菜单，高亮保存、导出和修改状态，提供常用快捷键及重新打开引导的位置。

聚光开孔允许操作真实控件；卡片会根据目标、窗口尺寸和其他聚光区域调整位置。包含移动聚光、发光边缘、连接线、步骤进度、操作反馈及完成动画。支持上一步、下一步、直接选择步骤、跳过、Esc 退出和键盘导航，尊重动效开关与减少动态效果偏好。

引导使用临时演练文档。完成或中途退出时恢复进入前的未保存内容、编辑方式、视图、侧栏、专注状态、排版、摘要偏好和导图缩放；演练文档从列表移除。引导不会自动保存或下载，只有用户点击保存 / 导出时才生成演练文件副本。

## 导图规则与交互

- 标题按 H1–H6 组成主干；跳级标题挂到最近的上级。单个开头 H1 作为根节点；无 H1、多 H1 或标题前有正文时使用文件名作为文档根。
- 段落与引用作为淡色、虚线内容节点，列表保留缩进层级。代码块内的标题符号不进入主干；代码块、表格默认隐藏，可开启摘要。
- 按段落合并多行正文，先去掉常见 Markdown 标记，再按可见字形截取。默认 **30 字**，可配置 **1–120 字**；省略号不计入，中文、英文、标点与 emoji 均按字形计数。
- 摘要仅用于显示，点击节点查看全文；调整设置不会修改源文档。显示偏好在浏览器本地保存。
- 可分别隐藏段落、列表、特殊块；全部隐藏时只显示标题。支持单分支折叠、收起分支 / 展开全部、拖动平移、滚轮平移、Ctrl / Cmd 加滚轮缩放及适应画布。
- 默认布局最低保留 75% 比例，避免窄窗口文字过小；超出的分支通过拖动查看。点击“适应画布”可以缩小查看整图。
- 视图切换、侧栏显隐、分支重排、浮层出现、缩放和章节定位有短动画；尊重系统的“减少动态效果”偏好。

## 从 Zhijian 接入的建议

脑图与配套主题已统一迁入 `CodeWF.Avalonia.MindView` NuGet 包。Vex 使用库内只读 Markdown AST 结构图，Zhijian 使用同包的编辑型脑图：

1. 从 Markdown AST 构建展示树，并携带每个节点的源码范围；正式接入不要直接使用原型的简化解析器或现有按行导入器。
2. 为导图控件提供只读模式，保留选择、折叠、平移和缩放，关闭新增、删除、拖动改层级及节点文字编辑。Markdown 是唯一内容来源，第一期聚焦查看与导航。
3. 完整内容与摘要分开存储，截断只在展示层发生。不要把截断后的文字写入 Markdown 或覆盖节点全文。
4. 复用 Vex 语义主题令牌；MindView 不依赖 AtomUI、Semi 或 Ursa，浅深模式和主题色由宿主传入。
5. 源码修改防抖刷新，尽量保留展开状态、选择、缩放和平移；长文档需原生性能验证。

原生视图、设置持久化和源码定位已接入；长文档性能、多 DPI 与中文输入法组合输入需持续实机验收。

## 验证与边界

```powershell
npm ci --prefix design/tests
# 首次使用时，在 design/tests 中运行 npx playwright install chromium
npm test --prefix design/tests
```

检查八色 × 浅深组合、系统主题、菜单入口、三个视图、摘要配置与持久化、Unicode 字形、源码定位、折叠与缩放、即时输入效果、取消与撤销、跨块定位、18 套排版与持久化、HTML 样式导出、快捷键、无图标菜单对齐、键盘导航、保存副本、取消切换、5 步引导、完成 / 退出的内容与偏好恢复、入口持久化、窄窗口和减少动态效果。

原型可读取选中的 Markdown 文件、下载 Markdown 副本与独立 HTML；不会覆盖原文件。示例内容与编辑内容只保留在当前页面内存中，刷新后重置。菜单与关于使用应用的简体、繁体、英语、日语资源，语言偏好本地保存。关于版本与版权从构建属性生成，构建时间统一为原型样例 `2026-10-15 00:00:00`，不代表生产二进制的实际编译时间。主窗体保留桌面边框、标题栏及三枚窗口按钮；右侧提供浅/深/系统循环三态按钮、八个平铺配色色点和语言图标菜单，不增加配色或模式下拉框。语言菜单来自资源列表，便于扩展。关于保留现有遮罩浮层。

关于提供检查、下载、校验、安装及对应失败重试、取消和缺少安装包等七种状态演示，不请求网络、不执行安装器。新建窗口、打开文件夹、编码重开、最近记录清空、PDF、Word、PNG、平台富文本复制、MCP、打印和原生窗口操作仍为演示入口；Markdown 渲染仅覆盖原型需要的常见块，完整 GFM、复杂嵌套、输入法组合输入与大文档性能需正式接入时验证。新增审计覆盖四语言菜单和关于、生成元数据、桌面框架、固定时间和完整更新状态。

## 单文件交付

`design/` 中的主 HTML 已内嵌样式、脚本、图标和图片。只复制这一个 HTML 到空目录即可离线查看并操作，无需旁边的资源文件或本地服务。

维护源码放在 `scripts/prototype/`；执行 `pwsh scripts/build_standalone_prototype.ps1` 重新生成，`-Check` 校验生成文件。不要直接修改交付 HTML。交互审计会复制 HTML 到空目录，阻止其他文件和网络资源请求，并检查脚本错误与图片完整性。
